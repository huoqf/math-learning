## 二、P0 级问题（附验算过程）

### P0-1　独立性容差 0.015 → 非独立被判独立 + 输出假等式

**位置**：`src/math/probabilityIndependence.ts:139-141`
```ts
const isIndependent = Math.abs(productDiff) < 0.015 && safePA > 0 && safePB > 0;
```

**验算 A（互斥被判独立）**：`pA`/`pB` 的 registry 下限均为 **0.1**（`registries/probabilityIndependence.ts:41,47`，滑块可达）。
取 `pA = pB = 0.1`、`λ = 0` → `minPAB = max(0, 0.2−1) = 0`，`P(AB) = 0`，`P(A)P(B) = 0.01`，`|Δ| = 0.01 < 0.015` ⇒ **`isIndependent = true`**，同时 `isMutuallyExclusive = true`。
- 中屏 `components/ProbabilityIndependenceScene.tsx:161-165` **先判 `isIndependent`** ⇒ 徽标显示「★ 相互独立 (P(AB) = P(A)P(B))」，而同一帧两圆分离（画的是"无交集"）；
- 右屏 `builders/probabilityIndependence.ts:144-149` ⇒ `P(B|A) = 0.00/0.10 = 0.00 = P(B)`（P(B)=0.10），detail 写「满足 P(AB)=P(A)P(B) 且 P(B|A)=P(B)……因 P(AB) > 0，两集合不互斥」；
- 同页 `:246-250` 的 danger 警示又写「此时两事件**绝对不独立**」⇒ **同屏自相矛盾**。
- 正确结论：互斥且 `P(A),P(B) > 0` ⇒ **必不独立**（`0 = P(AB) ≠ P(A)P(B) > 0`）。

**验算 B（近独立被判独立）**：默认 `pA=0.5, pB=0.4`，把 `λ` 拖到 **0.47**（step 0.01，两次点击可达）→ `P(AB) = 0.47×0.4 = 0.188`，`P(A)P(B) = 0.2`，`|Δ| = 0.012 < 0.015` ⇒ 判独立；右屏显示 `P(B|A) = 0.188/0.5 = 0.376 = P(B)`，而 `P(B) = 0.40` ⇒ **假等式**。误判带为 `λ ∈ [0.46, 0.54]`，整个区间都错。

**根因**：绝对容差 + 布尔量未做互斥排除（`relationType` 已正确落 `"neither"`，但 `isIndependent` 没跟上）。
**修法（整体方案）**：① 容差改**相对量级**（如 `|Δ| ≤ 1e-9·max(1, P(A)P(B))`）；② `isIndependent` 追加 `&& !isMutuallyExclusive`；③ 数值不相等时**必须渲染 `≠`**（或统一 `≈` 并在文案注明近似），禁止在不等时输出 `=`。

### P0-2　统计页偏态判定与自身数据整体反向

**位置**：`src/data/builders/statPercentile.ts:47-53`（`skewText`）、`:116-124`（定理卡片）
**生成式**：`src/math/statPercentile.ts:123-169`（6 组 [40,100)，组距 10，`factor = 1 + shift·(i−2.5)·0.35` 后归一）

我用 Node 逐组复算（Mo=最高矩形中点、Me=面积二等分、x̄=组中值加权）：

| shift | 生成值 Mo / Me / x̄ | 实际偏态 | 页面输出文字 | 判定 |
|---|---|---|---|---|
| **0**（默认/自由探索/新高考6组/课本5组） | 65.00 / 70.00 / **71.00** | Mo<Me<x̄ ⇒ **右偏** | 「对称钟形分布: 众数 ≈ 中位数 ≈ 均值」 | **错** |
| **+0.6**（预设「正偏态(右偏长尾)」） | **75.00** / 74.18 / 74.58 | Mo 是**最大**的，非严格单调 | 「众数 < 中位数 < 均值」 | **错** |
| **−0.6**（预设「负偏态(左偏长尾)」） | 65.00 / 66.52 / **67.27** | Mo<Me<x̄ ⇒ **右偏** | 「均值 < 中位数 < 众数」 | **错** |

**要点**：三档**全部反向或失配**，且**默认态就错**（默认 `shift=0`，页面写"对称"，实测 Mo=65 与 x̄=71 差 6 分）。
中屏直方图与右屏三个数字都是对的 —— **只有判定文字错**，学生读到的是与图完全相反的结论。这是该页最核心的教学产出。

**根因**：`shift` 只线性改频率，且 `Math.max(0.02, ·)` 兜底把众数钉在未被压低的组（shift=+0.6 时 Mo 反而最大）；文案却按教科书「右偏 ⇒ Mo<Me<x̄」**写死**。
**修法（整体方案）**：不要写死结论 —— **按当次生成的 Mo/Me/x̄ 实时比较**输出偏态，并对「非严格单调」（如 Mo>Me>x̄）给出独立描述或标注为「形态非典型，不作标准偏态讨论」；若要保留三档预设，需先把频率生成式改成真正能产生对应偏态的形式（并加断言：右偏预设必须满足 Mo<Me<x̄）。

### P0-3　分层抽样「两层合并」场景 nᵢ 之和 ≠ n

**位置**：`src/data/registries/statPercentile.ts:139-157`（`twoStrata`：`sampleN=80, N1=400, N2=600, N3=0`）＋ `src/math/statPercentile.ts:332-336`
```
const strataSampleN = [Math.max(1, roundedCounts[0]), Math.max(1, roundedCounts[1]), Math.max(1, roundedCounts[2])];
```
**验算**：`totalN = 1000`，`ratio = 0.08` → `rawCounts = [32, 48, 0]` → `roundedCounts = [32, 48, 0]`，Σ = 80 ✓；但 `Math.max(1, 0)` 把第 3 层抬到 **1** ⇒ 输出 `(32, 48, 1)`，**Σ = 81 ≠ n = 80**。
同页定理明确写 `∑nᵢ = n`，math 层注释也写「各层分配抽样数 n_i（**和恰好等于 sampleN**）」⇒ 右屏数字**违反自己的定理**。
（中屏 `StatPercentileStratifiedScene` 以 `N > 0` 过滤第 3 层，所以只有右屏暴露。）

**修法**：`Math.max(1, ·)` 仅对 `Nᵢ > 0` 的层施加（`Nᵢ = 0` 的层分配数应为 0）；或把 `twoStrata` 的 `N3.min` 抬到 > 0，使场景与声明域自洽。

### P0-4　概率递推：λ=1 时不动点 0/0 被硬编码成 `1.000`，同页出现两个不动点

**位置**：`src/features/probabilityMarkov/components/modeConfig.ts:28`（`tStr = … : "1.000"`）＋ `src/data/builders/probabilityMarkov.ts:110`（无条件写 `t = p₂₁/(1−λ)`）
**可达性**：`p1/p11/p21` 声明域均为 `[0,1] step 0.05`（`registries/probabilityMarkov.ts:53-79`），且顶部公式条**无条件渲染**（`Animation.tsx:52` 直接用 `params` 求值）⇒ 取 `p₁=0.75, p₁₁=1.00, p₂₁=0.00` 即命中。

**验算**：`λ = 1` ⇒ `denom = 0`。
- math 层 `math/probabilityMarkov.ts:69,75`：`isDegenerate = true` ⇒ `pStationary = initP1 = **0.750**`；
- 中屏 `components/MarkovScene.tsx:1291` 输出「平衡不动点 t = **0.750**」；
- 顶部公式条 `modeConfig.ts:28` 走 `else` 分支 ⇒ 输出 `p_{n+1} − **1.000** = 1.00(p_n − 1.000)`；
- 右屏 `builder.ts:110` 的 note 打印 `t = \frac{p_{21}}{1-\lambda} = 0.750` —— 而该式在 λ=1 时是 **0/0** ⇒ **结论取自退化分支、推导却是假命题**（"结论对、推导假"最危险：结论验算会通过，学生照抄推导却丢过程分）。

**修法（整体方案）**：`|1−λ| < 1e-6` 时**三处统一走退化分支**：公式条与 note 都改写成 `λ = 1 ⟹ p_{n+1} = p_n ⟹ p_n ≡ p₁`（吸收/自封闭，不动点方程退化、不存在唯一不动点）；**删除字面 `"1.000"` 回退**，禁止在退化态挂 `0/0` 形式的式子。

### P0-5　概率递推：λ=−1 在三处被说成三种不同的事

**位置**：`builders/probabilityMarkov.ts:119-123`（定理 note）、`:133-137`（gaokaoPoints）、`components/MarkovScene.tsx:1193-1195`（中屏徽标）
**可达性**：`p₁₁ = 0.00, p₂₁ = 1.00` ⇒ `λ = −1`。

**验算**：`math/probabilityMarkov.ts:70` `isPureOscillating = true`；`:71` `isOscillating = λ < −1e-6 && !isPureOscillating` ⇒ **false**。于是：
- `builder.ts:120` 用 `isOscillating` 二选一 ⇒ 落入 `else`，输出「公比 **0 ≤ λ < 1**：单调递进逼近」（λ=−1 显然不满足 `0 ≤ λ < 1`）⇒ **错**（同样的错在 `:135-136` 复制到 gaokaoPoints）；
- 中屏 `MarkovScene.tsx:1193-1195` 用 `λ < 0` 判据 ⇒ 输出「λ = −1.00 < 0：交替**阻尼**振荡」⇒ 实为**等幅**永久振荡、无衰减；
- 而 math 层 `:137` 自己写的是「**永久等幅振荡，不会趋近于单一稳定值**」。
⇒ 同一退化态在同一页面出现**三种口径**，其中两种是错的。

**修法**：把 `isDegenerate`（λ=1）/`isPureOscillating`（λ=−1）提升为**贯穿三处的独立分支**（builder 定理 note、gaokaoPoints、中屏徽标），文案统一为「等幅振荡（无衰减）」/「恒等常数列」。
