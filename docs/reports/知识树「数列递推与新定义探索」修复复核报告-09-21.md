### ❌ NEW-1（建议按 P1 处理）：几何片段场景空态卡取到**硬编码回退值 3**

**文件**：`src/features/sequence/components/SequenceGeometricSegmentScene.tsx:36`


`validK` 被空态卡（L182/191）与分色分组（L45）使用。当 `segmentedSums === null`——**正是空态卡要服务的那一种情形**——`validK` 退化为硬编码 `3`，与用户真实所选 `kSegment` 无关。

**渲染级实测**（两页同一操作 `N=6, kSegment=4`）：

**修法（最小改动，一行）**：
```ts
const { geoData, kSegment } = useSequenceParams(params);
```

（`useSequenceData.ts:29,89` 已导出 `kSegment = params.kSegment ?? 3`，等差页即如此取用。）
