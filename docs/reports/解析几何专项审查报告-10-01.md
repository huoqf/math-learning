## 二、总体结论

**正面（这批页面的数形底子仍然在线）**：

- 09-18 治理报告判定的 **5 项 P0 数学错误 + 主要 P1 项全部真落地**（详见 §七 落实度对照），无一退回。
- 纯数学层的关键恒等式经独立验算**全部成立**：双曲线焦点弦「倒数和/倒数差」按焦点是否落在弦内分支（两种构型均 = `2a/b²`）、抛物线全部焦点弦公式（四方向）、点差法三类曲线、齐次化全套系数、切点弦/极线三类方程、焦点三角形面积、阿基米德三角形与正交弦恒等式。
- 中屏特征元素基本标齐：圆锥曲线必画焦点（双曲线有渐近线、抛物线有准线+焦点）、切线问题有切点+切线、极点极线有极线、`PA⊥PB` 有直角符号。

**但存在三类实质问题**：

1. **P0 · 中屏点标坐标系传参错误（用户可见，3 页受害）** —— `MathPoint` 的 `x/y` 是设计像素槽，这三页却把数学坐标灌了进去，导致**焦点、交点、垂足、弦中点全部画到画布左上角**；而同页的 `InteractivePoint`（传数学坐标）与标签（用已算好的设计坐标）位置正确 ⇒ 学生看到「点在一处、标签在另一处、曲线在第三处」。这类缺陷**结构上不可能被现有测试发现**。
2. **P0 · 两处数学判据写错** —— 双曲线中点弦存在性判据漏掉一整支（滑块可达，右屏输出与同行 latex 自相矛盾）；双曲线「同支/异支」文字标签完全反向。
3. **P1 · 若干一致性缺陷** —— 推导链打印的等式左右不等（假等式）、无定义量被显示成具体值、中屏与右屏讲画不一致、滑块空转、预设参数走出视口、课标标注不规范、11 页集体缺拖拽钳制 SSOT。

**完整性（用户第一问）**：**未完整覆盖**。人教A版选必一 **2.4 圆的方程整节无承载页**（标准方程↔一般方程互化、配方求圆心半径、点与圆位置关系的代数判定、待定系数法求圆的方程），另 **2.3 两点间距离公式**、**2.1 倾斜角与斜率的独立探究**亦无独立承载。详见 §五。

### P0-2 ★★★ `conicLine` 双曲线中点弦存在性判据漏掉一整支（滑块可达，右屏自相矛盾）

- **位置**：`src/math/conicLine.ts:157`

```ts
} else if (conicType === "hyperbola") {
  if (Math.abs(y0) > 1e-5) { k = (b * b * x0) / (a * a * y0); }
  isMidpointValid = (x0 * x0) / (a * a) - (y0 * y0) / (b * b) < 0;   // ← 只取了 w<0 一支
}
```

**独立推导**：双曲线 `b²x²−a²y²=a²b²`，代入点差法强制的过 M 直线（`k=b²x₀/(a²y₀)`, `m=y₀−kx₀`）：

```
A = b²−a²k² ,  B = −2a²km ,  C = −a²(m²+b²)
Δ = B² − 4AC = 4a²b² · w(w−1) ,   其中 w = x₀²/a² − y₀²/b²
```

⇒ **实弦存在 ⟺ Δ>0 ⟺ w<0 或 w>1**。代码只判 `w<0`，**漏掉 `w>1`（同支弦）**。

**数值验算（滑块可达）**：`a=2, b=2, M(2.9, 0.2)` ⇒ `w = 2.0925 > 1`

| 项 | 值 |
|---|---|
| 判别式 Δ = 209.25x²−1213.65x+1755.42 的 Δ | **58523 > 0** |
| 两交点 | x = 2.7554 / 3.0446 |
| 弦中点实测 | **(2.9000, 0.2000) ≡ M** ✓ |
| 代码判据 `w<0` | `false` ⇒ 判「无效」 |
| 真实结论 | **存在实弦** |

`registry` 可达性：`a∈[1,5]`、`b∈[0.5,4]`、`x0∈[−3,3]`（`src/data/registries/conicLine.ts:369-499`）⇒ `a=2,b=2,M(2.9,0.2)` 完全可达。

**危害链**：
1. `src/data/builders/conicLine.ts:395-398` 因 `!isMidpointValid` 走 `\le 0` 分支，文案输出「**无实数中点弦**」，而**同一行 latex 打印的 Δ 是正数**（58523）—— 与 09-18 报告 P0-3/P0-4 同类「公式与实际数值不自洽」硬伤；
2. 中屏按 `status="secant"` 正常画出实弦（`conicLine.ts:363-374`），右屏却断言"无弦" ⇒ **数形冲突**；
3. 该结论落在学生最易背下来的"中点弦存在性充要条件"上。

**修法**：判据改 `w*(w-1) > 0`（即 `w < 0 || w > 1`），与判别式同源。

### P0-3 ★★★ `lineParamT` 双曲线「同支 / 异支」文字标签完全反向

- **位置**：`src/data/builders/lineParamT.ts:357-360`（`reciprocalFormula`）与 `:361-362`（`reciprocalNote`）

```
t_1 t_2 < 0  ↔  割线交于双曲线两支（异支），倒数和 √Δ/|C|
t_1 t_2 > 0  ↔  割线交于双曲线同支，倒数差 |B/C|
```

**独立验算**：双曲线焦点 `F(c,0)`，直线 `x=c+t cosα, y=t sinα` 代入得 `A=b²cos²α−a²sin²α`、`C=b⁴`，故 `t₁t₂ = C/A`。取 `a=3, b=2`（c≈3.6056）：

| α | t₁ | t₂ | t₁t₂ | 交点 x | 所在支 | 结论 |
|---|---|---|---|---|---|---|
| 45° | −0.7206 | +8.8794 | **−6.400** | 3.096 / 9.884 | **同在右支 ⇒ 同支** | `t₁t₂<0` ↔ **同支** |
| 20° | −0.6262 | −10.3078 | **+6.454** | 3.017 / −6.079 | 一右一左 ⇒ **异支** | `t₁t₂>0` ↔ **异支** |

（注：`√Δ = 2ab²`，与 α 无关，故 t 有闭式 `t = b²(−c cosα ± a)/A`。）

⇒ 正确关系是 **`t₁t₂<0` ↔ 同支（内分，F 在弦内）、`t₁t₂>0` ↔ 异支（外分）**，与现文案**正好相反**。`reciprocalNote` 的「异支时定点在两支之间」亦错（外分时定点不在两交点之间）。

**可达性**：`conicParamT` 页左屏 `conicType` 可取 `"hyperbola"`（`LineParamTAnimation.tsx:89, 128`），`gaokaoModel` 可取 `"reciprocal"` ⇒ 该定理卡用户可见。

**说明**：`:187` 的公式选用逻辑 `isInternal = tProd < 0`（内分 → `√Δ/|C|`）**本身自洽正确**，错的只是这两处**中文标签** —— 属"公式对、结论文字反"，学生照文字记忆必错。

**修法**：交换"两支/同支"两处字样，并重写 `reciprocalNote`。
