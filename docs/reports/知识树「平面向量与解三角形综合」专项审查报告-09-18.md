## 三、P0 级问题（数学错误 / 会直接把错误教给学生）

### P0-1 ★★★ 数量积垂直判定"充分不必要"写反（方向完全颠倒）

- **位置**：`src/data/builders/vectorDotProduct.ts:245`（高考要点卡）
- **触发**：`/vector-dot-product` 页任意模式，右屏"高考要点"第 2 条

原文：

> 「易错点辨析：**a·b = 0 是 a ⊥ b 的充分不必要条件** (需排除零向量)。a ⊥ b 充要条件为 x₁x₂ + y₁y₂ = 0；而 a // b 充要条件为 x₁y₂ − x₂y₁ = 0，严禁记混！」

**验算**：取 `a = (1,0)`、`b = (0,0)`。

| 命题 | 真假 | 依据 |
|---|---|---|
| `a·b = 0 ⇒ a ⊥ b` | **假** | 已成立 `a·b = 0`，但 `b` 是零向量、夹角无定义，`a ⊥ b` 不成立 → **不充分** |
| `a ⊥ b ⇒ a·b = 0` | **真** | 恒成立（对非零向量）→ **必要** |

**结论**：正确表述是「**a·b = 0 是 a ⊥ b 的必要不充分条件**」。原句把方向说反了。

**危害最高，因为该页自己就自相矛盾**：同一 builder 的 `:223` 写着「a, b 为非零向量时，a ⊥ b 充要条件为 a · b = 0」，`:257` 又写「零向量方向不定，不能定义投影向量与夹角」——这三处拼在一起，学生必然记反。

### P0-2 ★★★ 诱导公式六把"逆时针旋转 90°"写成"关于直线 y = −x 对称"

- **位置（右屏）**：`src/features/trigIdentity/math/trigIdentity.ts:378-379` → 经 `src/data/builders/trigIdentity.ts:274` 渲染为定理卡的「适用前提」与 note
- **位置（中屏）**：`src/features/trigIdentity/components/TrigIdentityScene.tsx:603-624`
- **触发**：`/trig-identity` 页 → 公式六（π/2 + α）

原文：

```

symmetryName   = "关于直线 y = -x 对称 / 逆时针旋转 90°";
symmetryLineTex = "y = -x";
```

**验算（α = 30°）**：P = (cos30°, sin30°) = (0.8660, 0.5000)，β = 120°，P′ = (−y, x) = (−0.5000, 0.8660)。

| 变换 | 像 | 是否等于 P′ |
|---|---|---|
| 关于 **y = −x** 轴对称：`(x,y) → (−y,−x)` | (−0.5000, **−0.8660**)，对应角 240° | ❌ |
| 绕原点**逆时针旋转 90°**：`(x,y) → (−y, x)` | (−0.5000, **0.8660**），对应角 120° | ✅ |

且 P、P′ 的垂直平分线过原点、倾角恒为 `α + 45°`（随 α 变化），**不存在任何固定直线**使 P → P′ 为轴对称。**该变换本质是旋转，不是反射。**

**代码自身也自相矛盾**：`math/trigIdentity.ts:395` 的 `step3Verify = "动点 P(x, y) 旋转 90° 变为 P'(-y, x)"` —— 同一个 switch 分支里，一处说"旋转 90°"、一处说"关于 y=−x 对称"，两者不可能同时成立。

**中屏错上加错**：`TrigIdentityScene.tsx:579-580` 的条件是

```tsx
{(activeInd.symmetryType === "diag_pos" ||
  (activeInd.kValue === 1 && activeInd.isOdd)) && ( ...画 y = x... )}
```

而公式六的 `kValue = 1`、`isOdd = true`，条件命中 → 画 **y = x**；紧接 `:603` 的 `symmetryType === "diag_neg"` 又画 **y = −x**。**中屏在一次演示里同时画出两条"对称轴"，两条都不是该变换的对称轴。**

**正确处置**：π/2+α 的几何本质是"终边绕原点逆时针旋转 90°"，中屏应改为画**旋转方向弧箭头 + P、P′ 两点**（参照本页 `complementary` 模式的正确做法），而不是任何一条直线。

### P0-3 ★★★ 三角函数线「面积放缩链」的推导步是假命题，且中屏图元不配套

- **位置（右屏）**：`src/data/builders/trigLines.ts:206`（定理 note）、`:204`（同一错误的 latex）、`:231`（口诀）
- **位置（中屏）**：`src/features/trigLines/components/TrigLinesComparisonScene.tsx:342,391`（柱状图标签与结论）、`TrigLinesAnimation.tsx:115`（悬浮公式）
- **触发**：`/trig-lines` 页 → 面积对比模式（`comparison`）

原文：

> `:204` `S_{△OMP} < S_{扇形OAP} < S_{△OAT} ⟹ sin x < x < tan x`
> `:206` 「同一面积不等式两边同除以 (1/2)cos x 即得 sin x < x < tan x」
> `:231` 「面积包含直观见：小直角三角形 ⊂ 扇形 ⊂ 大直角三角形，两端除以 (1/2) 即得 sin x < x < tan x！」

**验算（x = 60°）**，`src/math/trigLines.ts:154` 的实际取值：

| 量 | 值 |
|---|---|
| S₁ = S_△OMP = ½·sin x·cos x = ½·0.8660·0.5000 | **0.2165** |
| S₂ = S_扇形 = ½·x = ½·1.0472 | 0.5236 |
| S₃ = S_△OAT = ½·tan x = ½·1.7321 | 0.8660 |

按 `:206` 所述"两边同除以 ½cos x（= 0.25）"：

| 项 | 计算 | 结果 |
|---|---|---|
| 左 | 0.2165 ÷ 0.25 | 0.8660 = sin x |
| 中 | 0.5236 ÷ 0.25 | **2.0944 ≠ x = 1.0472** |
| 右 | 0.8660 ÷ 0.25 | **3.4641 ≠ tan x = 1.7321** |

即该除法只能得到 `sin x < x/cos x < tan x/cos x`，**得不到** `sin x < x < tan x`。`note` 与 `口诀` 均为**明确的假命题**。

**根本原因**：`△OMP` 的面积是 `½ sin x cos x`，不是 `½ sin x`。要得到 `sin x < x`，必须用 **`△OAP`**（面积 = `½·|OA|·sin x = ½ sin x`），即链条应为

```
△OAP ⊂ 扇形OAP ⊂ △OAT  ⇒  ½ sin x < ½ x < ½ tan x  ⇒  sin x < x < tan x
```

（注：`:193-200` 那条定理的 latex `S_△OMP < S_扇 < S_△OAT ⟹ sin x cos x < x < tan x` 是**对的**；错误发生在把它改写成"sin x < x < tan x"的第二条定理与口诀处。）

**结论正确、推导链是假的** —— 学生照抄这套推导写进解答题，过程分必丢。中屏柱状图把 `S₁ (△OMP)` 与结论 `⇒ sin x < x < tan x` 直接连线，与右屏同错，形成"图文互证"的假闭环。

**附带（P2）**：柱状图宽度 `Math.min(60, area*80)`（`ComparisonScene.tsx:347,360,378`）在 x = 85° 时 S₂ = 0.7418 → 59.3px、S₃ = 5.715 → 被截到 60px，**视觉上 S₂ ≈ S₃**，"三阶包含"的直观被破坏（x = 75° 亦然）。
