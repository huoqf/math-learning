## 2. 本轮核心：`arch/no-builder-raw-calc` 扫描内核重写

### 2.1 为什么要重写（不是加宽正则）

六轮实测证明"逐行正则 + 变量名白名单"存在**结构性**失效 —— 且失效方式恰好是 prettier 的默认行为：

| 漏过的写法 | 旧实现失效原因 |
|:---|:---|
| `const circumRadius =`<br>`  Math.sqrt(a * a + b * b);` | 逐行匹配，超长表达式被 prettier **折行**后第一行不含 `Math.sqrt` ⇒ **格式化即失效** |
| `` value: `${Math.sqrt(a * a + b * b).toFixed(2)}` `` | 正则要求先出现几何度量变量名，**内联无变量**时不匹配 |
| `const e = Math.sqrt(...)` / `const s = Math.hypot(...)` | 白名单为 `[Rrdlh]`，**不含 `e`/`s`/`k`** 等单字母 |
| `` tex={`E(0,0,${(lambda * (c)).toFixed(2)})`} `` | 要求 `lambda\s*\*\s*c` **直接相邻**，夹括号即失效 |

### 2.2 新内核设计

`FileContext.cleanContent` 已由状态机剥离注释，故改为**字符级**扫描（`architecture.mjs`）：

1. **括号配对定位实参** —— `Math.sqrt|hypot|pow(` 后用 `matchParenForward` 取**真实实参**，跨行/跨缩进天然无关；
2. **运行时标识符判定** —— 实参剔除 `Math.PI/E/SQRT2/...` 常量后仍含标识符才算"对入参重算"，从而**不误伤公式里的无理常数系数**；
3. **`** 0.5` / `^ 0.5`** —— 用 `matchParenBackward` 回溯**左操作数**再判定，跨行 `** 0.5` 同样命中；
4. **字符下标 → 行号回映** —— 报告行号仍精确到"语句所在行"，`audit-disable-next-line` 语义不变；
5. **作用域分档** —— `solid` 专题文件（`builders/solid*.ts` + `features/solidGeometry/**`）**不设名称门槛**（任何开方都是几何度量裸算）；其余 builder 保留几何度量词表门槛。

### 2.3 四类漏过 → 全部命中（实测）

| 写法 | 旧 | 新 |
|:---|:---:|:---:|
| 跨行赋值 `const circumRadius =` ⏎ `Math.sqrt(...)` | 漏过 | **拦截** |
| 实参跨行 `Math.sqrt(` ⏎ `a*a+b*b,` ⏎ `)` | 漏过 | **拦截** |
| 内联无变量 `` `${Math.sqrt(a*a+b*b).toFixed(2)}` `` | 漏过 | **拦截** |
