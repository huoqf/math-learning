## 二、 核心问题与整体修复方案落地清单

### 1. 纯数学模型层（Zero Side-effects）
- **P0 独立性与互斥假独立消除** (`src/math/probabilityIndependence.ts`)：
  - 弃用绝对/相对容差判据（旧容差法在两位小数展示下仍会产生 513 组“右屏显示 $P(B|A)=P(B)$、却被判为不独立”的反向假不等式），改为**量化到展示网格**判据：`quantizeProb(v) = round(v × 10^MATH_PROB_DECIMALS)`，当且仅当量化后的 $P(B|A)$ 与 $P(B)$ 相等才判独立；
  - `MATH_PROB_DECIMALS = 4` 由 `src/utils/mathFormat.ts` 统一导出，`formatMathProb`（右屏展示）与 `quantizeProb`（数学判定）共用同一常量，从根上保证“右屏显示相等 ⟺ 数学判独立”；全 (pA, pB, pAB) 可达网格 **2 万+ 组合**已由测试遍历验证；
  - 增加正概率互斥排他约束：当 $P(A) > 0, P(B) > 0$ 且 $P(AB) = 0$ 时，严格标记为“互斥必然不独立”，杜绝小概率极端下被误判为独立的重大科学性漏洞。
- **P0/P1 偏态分布判定与分层抽样守恒** (`src/math/statPercentile.ts`)：
  - **重构频数生成器**：旧实现“对称骨架 × 线性因子”把众数钉死在组中点、弱偏斜下不迁移，导致中屏图形与右屏 $M_o < M_e < \bar{x}$ 判定脱节；新实现改用**双指数衰减**（峰值迁移 `peakIdx = centerIdx − shift` + 左右非对称衰减率 `leftDecay/rightDecay = 0.7×(1∓0.8·shift)`），保证 $shift$ **全域**（组数 ∈ {5,6,7,8} × shift ∈ [-1,1] 步长 0.1，共 84 组可达组合）图形与结论 100% 自洽；
  - 统一导出纯函数 `evaluateSkewness`，以 `mean − median` 与对称判据 `SKEW_SYMMETRY_EPS = 0.02` 判定偏态方向，并新增 `relationLatex` 字段（$M_o < M_e < \bar{x}$ / $\bar{x} < M_e < M_o$ / $M_o \approx M_e \approx \bar{x}$）作为右屏推导链的**唯一事实源**，消除第二套判定口径；
  - **组数档位补全**：`BinCountOption` 由 `5|6|8` 扩为 `5|6|7|8`，注册表新增“7组(过渡)”档位，且 7 组必须真实渲染 7 根柱；
  - 修复分层抽样算法：对人口规模为 0 的空层（$N_i = 0$）严格分配 0 个样本，规避历史 `Math.max(1, ·)` 强行保底导致的样本总和越界 $\sum n_i = 81 \ne 80$。
- **P0/P1 马尔可夫链退化与动力学完备性** (`src/math/probabilityMarkov.ts`)：
  - 引入 `MarkovDynamicType` 四态动力学分类枚举（`convergent_monotonic` 单调收敛、`convergent_damped` 阻尼振荡、`pure_oscillating` 纯等幅振荡、`degenerate_constant` 恒等常数列）；
  - 完备支持转移公比 $\lambda = 1$（退化常数列，各步恒等于初值 $p_1$）与 $\lambda = -1$（纯等幅两值振荡）；
  - 递推通项规范消灭超纲 $\lim$ 符号，改用课标规范的中文渐近趋向描述。
- **P0 双分布对比参数同源** (`src/math/probabilityDistribution.ts`)：
  - 二项分布与超几何分布对比模式导出真实次品数 $M = \mathrm{round}(N \cdot p)$ 与真实不放回成功概率 $actualP = p_0 = M / N$；
  - **方差同源（P1-4）**：二项分布改为共用同一 $p_0 = M/N$（`computeBinomialDistribution(sampleN, actualP)`），使两分布方差仅相差有限总体修正系数 $\frac{N-n}{N-1}$，右屏方差公式统一写作 $D(X_{\text{超}}) = n p_0 (1-p_0)\cdot\frac{N-n}{N-1}$；
  - 全链路（registry `labelFormula`、builder 期望/方差/定理/警示、`modeConfig` 公式条）统一由 $p$ 改为 $p_0 = M/N$，杜绝“二项用设计 $p$、超几何用实际 $M/N$”的口径分裂。

### 2. 场景注册表与配置治理
- **P0 正态分布 $2\sigma$ 准则与标准差错位修复** (`src/data/registries/probabilityNormal.ts`)：
  - “零件尺寸质检”场景公差范围统一设定为 $[\mu - 2\sigma, \mu + 2\sigma] = [19.8, 20.2]$，合格率精准对齐课标 $95.45\%$；
  - 纠正参数预设中将容差 $0.2$ 误标为 $\sigma$ 的错位。
- **P0 集合事件运算差事件语义纠正** (`src/data/registries/probabilityEvents.ts`)：
  - “包含关系”与“奇偶包含”等场景的高亮操作由容易误导的交集改为准确的差事件 `"onlyB"` / `"onlyA"`。
- **P1 先修知识依赖拓扑倒置消除** (`src/features/statPercentile/meta.ts`)：
  - 移除必修二统计对选必三正态分布的倒置先修依赖，恢复纯净先修图谱。
- **P1 古典概型摸球无放回容量锁定** (`src/data/registries/probabilityClassical.ts`)：
  - 锁定 2 红 3 白固定容量（总体 $N=5$，不放回样本空间容量 $n=20$），避免用户滑动球数导致与固定题设和右屏公式脱节。
- **P1 概率递推课标外术语清理** (`src/data/registries/probabilityMarkov.ts`)：
  - 清理题设中残留的“平衡稳态极限”与“平衡稳态值”，替换为纯正课标用语“渐近定值”与“不动点定值”。

### 3. 中屏场景与视口渲染
- **P0 杨辉三角超阶视口溢出** (`src/features/probabilityCounting/components/BinomialScene.tsx`)：

### 4. 右屏推导链与高考采分点收敛

## 四、 三轮复核与残留缺陷清除

本轮修复经历三轮独立复核，逐轮收紧判据、扩大验证域，最终清零以下**残留缺陷**：

| 轮次 | 复核发现 | 根因 | 终态修复 |
|---|---|---|---|
| 第 1 轮 | 4 项 P0 真正修复、1 项半修复（P0-2 默认态偏态）、1 项死配置（P1-6 古典概型锁定失效） | 局部补丁未触及生成器 | — |
| 第 2 轮 | 独立性存在 **513 组反向假不等式**；P1-4 方差不同源；排列组合缺 6 个推导分支 | 容差判据与展示口径不一致 | 量化判据 + $p_0$ 同源 + 6 分支补全 |
| 第 3 轮 | 偏态在 **shift 全域**下存在 18/84 方向错误；组数缺 7 档 | 对称骨架 × 线性因子的结构性缺陷 | 双指数衰减生成器 + 7 档补全 |

三处残留缺陷的共同根因均是**“展示口径 / 判定口径 / 生成模型三者未对齐”**，故本轮修复均从单一事实源（SSOT）入手：展示与判定共用 `MATH_PROB_DECIMALS`，右屏偏态结论单一取自 `relationLatex`，两分布方差共用 $p_0$。
