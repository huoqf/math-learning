## 二、 重点修复细节说明

### 1. 高斯倒序相加双分支与全零中性化保护
- **数学本质**：几何拼图法（两个阶梯拼成长方形）仅在 $a_i \ge 0$ 且 $\sum a_i > 0$ 时具有直观面积意义；一旦含负项或全零，几何拼图逻辑失效，必须转入基于对称轴的**代数配对和** $a_n + a_{N-n+1} = a_1 + a_N$。
- **落位表现**：
  - 正项：中屏拼合大长方形，横幅标明 `大长方形面积 = 2S_N = N × (a_1 + a_N)`；
  - 负项与全零：自动切为真实带符号双列柱，每列上方标注实际项值，两柱间标明 `和 = (a_n + a_{N-n+1})`，横幅准确归因：
    ```tsx
    (几何面积拼图需各项非负且和为正：本例不适用，代数对称相加恒等式依然成立)
    ```

### 2. 二阶递推模型适用域守卫
- **数学本质**：递推关系 $a_{n+2} = pa_{n+1} + qa_n$ 能构造降阶等比数列 $b_n = a_{n+1} - r_1 a_n$ 的充要条件是特征方程 $x^2 - px - q = 0$ 存在实数根，即判别式 $\Delta = p^2 + 4q \ge 0$。
- **落位表现**：
  - $\Delta < 0$ 时，中屏彻底移除虚假的 $b_n$ 散点与标签，右上角图例框切换为告警描边，明确给出 `Δ = p²+4q < 0，降阶等比不适用`；
  - 右屏面板同步输出无实根警示与通法局限性分析，左中右三屏完全同频。

### 3. 组件渲染级自动化契约测试建立
新建测试文件 [src/test/sequenceScenes.contract.test.tsx](file:///d:/code/math/math-learning/src/test/sequenceScenes.contract.test.tsx)，使用 `@testing-library/react` 挂载真实 SVG 节点：
1. `SequenceGeometricSegmentScene`：验证 $N=6, k=4$ 时精准渲染 `k=4` 与 `8 项`，断言不含默认值 `k=3`；$N=8$ 时空态卡自动消失并展示公比标签；
2. `SequenceArithmeticSegmentScene`：验证与等比片段场景保持完全相同的空态响应契约；
3. `SequenceArithmeticGaussScene`：
   - 正项断言渲染「大长方形面积」，屏蔽「代数配对和」；
   - 负项断言渲染「代数配对和」与中性归因文案，屏蔽几何长方形；
   - 全零 ($a_1=0, d=0$) 断言渲染代数配对和，**坚决断言不包含「含负项」**；
4. `RecurrenceSecondOrderScene`：$\Delta < 0$ 断言渲染「降阶等比不适用」且屏蔽 $b_n$ 图例与节点；$\Delta \ge 0$ 正常渲染降阶等比。
