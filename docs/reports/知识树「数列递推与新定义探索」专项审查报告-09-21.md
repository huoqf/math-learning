## 三、数学合规性（课标符合性）

### ✅ 符合项

1. **等差/等比数列**：通项、求和、下角标和性质、`S_n` 二次函数最值——完全落在课标必修范围。
2. **数列求和模型**：裂项相消、错位相减——课标与高考解答题主干，符合。
3. **一阶线性递推构造（平移/不动点）**：`a_{n+1} = p·a_n + q` 经不动点 `c = q/(1-p)` 平移为等比——属选择性必修「数学归纳法 + 数列」延展范围，教材例题常见变式，**判定为符合**。
4. **新定义差分探索**：预设 `new-def-diff`（a1=2, p=3, q=-2）数学完全正确（见 §六.1 数值核验）。

### ⚠️ 边界问题

**（M1）二阶递推「特征方程」超纲，且仍挂在课内节点下**

- `npm run audit:strict -- src/data/builders/sequence.ts` 报 **3 处 warning**：L990、L1013、L1020，均命中超纲术语黑名单「特征方程」。
- 该 3 处已带条目级 `isExtension: true` / `importance: "extend"`，**成功降级为 warning 而过门禁**——治理机制生效。

## 四、中屏动画合规性（**核心问题区**）

### 🔴 P0-1：高斯倒序拼图在负项/负公差下输出「负面积」

**文件**：`src/features/sequence/components/SequenceArithmeticGaussScene.tsx:29-31, 113-166`

**默认参数即触发**（`paramMeta`：`a1` 默认 1、`d` 默认 -1、`N` 默认 6）：

```
a = [1, 0, -1, -2, -3, -4]
sumHeightVal = a1 + aN = 1 + (-4) = -3
中屏文案输出 → 大长方形面积 = 2S₆ = 6 × (a₁ + a₆) = -18.0
6 项中 4 项为负；倒序柱向上叠负高柱
```

**机理**：组件用 `sumHeightVal = a1 + aN` 作为外接矩形高度（L31、L119、L158-159），**无任何正性守卫**：

```ts
const sumHeightVal = a1 + aN;            // L31
const ptTop = mathToDesign(1, sumHeightVal, scale);   // L119
const rectH = Math.abs(ptLeft.y - ptTop.y);           // L123
```

「倒序拼成长方形、面积 = 两倍和」这一**无字证明仅在正项、正公差数列下成立**。当 `d<0` 或含负项时，柱子落到 x 轴下方，「矩形」画在负半平面，文案直接打印 `-18.0`——这在数学上是**面积恒等式失效**，在教学中是**反例式误导**。

> 说明：高斯倒序相加的代数推导 `2S_n = n(a₁+aₙ)` 对任意等差数列都成立（含负项），但**几何拼图的面积解释不成立**。当前组件把「代数恒等式」与「面积可视化」混为一体，未区分有效域。

### 🔴 P0-2：二阶递推在 Δ<0 时中屏绘制「降阶等比」，与右屏 danger 警示**直接矛盾**

**中屏**：`RecurrenceSecondOrderScene.tsx:34, 46-119` —— **无条件**绘制 `b_n = a_{n+1} - r₁a_n` 散点（L99-106）并输出图例「构造降阶等比 bₙ」（L148-158），`calcSecondOrderRecurrence` 的 `delta` 从未参与判断。

**右屏**：`builders/sequence.ts:973-1017` —— 明确分支：

```ts
if (res.delta >= 0) { /* push 降阶等比项 b_N + 定理「构造降阶等比数列」 */ }
else { warnings.push({ text: "特征方程判别式 Δ = p²+4q = ... < 0，无实特征根...", level: "danger" }); }
```

**可达性核验**（`p_rec=-3, q_rec=-5, a1=1, a2=3`，均为滑块可达值）：

```
delta = -11  ⇒  Δ<0，右屏出 danger 警示、不列 b_n
中屏仍绘 b_n 点，且图例写「构造降阶等比 bₙ」
实测 b 相邻比值 = [-2.111, -0.632, 4.917, -4.017, -1.755]  ⇒ 并非等比
```

**后果**：同一时刻，中屏说「bₙ 是等比数列」、右屏说「无实特征根、该构造不成立」。学生无从判断谁对，**教具本身制造了知识冲突**。根因：中屏未接收 `delta`，缺少「模型适用域」判断。

### 🔴 P0-3：等长片段和 `null` 导致中屏与右屏**双空白**，无任何提示

**纯函数**：`src/math/sequence.ts:319-323`（等差）与 `L495-499`（等比）

```ts
const totalSegments = Math.floor(N / validK);
if (totalSegments >= 2) { segmentedSums = {...}; }   // 否则保持 null
```

**默认参数下 2 次交互即可触发**（`kSegment` 刻度档含 `k=4`）：

```

N=4, k=3  ⇒ floor(4/3)=1 < 2  ⇒ segmentedSums = null
N=4, k=4  ⇒ floor(4/4)=1 < 2  ⇒ segmentedSums = null
```

**消费端**均用可选链静默跳过：
