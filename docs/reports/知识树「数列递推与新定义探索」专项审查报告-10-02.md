**复现参数**：二次最值模式，`a₁ = −3, d = 0, N = 6`（滑块域 `d ∈ [−3, 3] step 0.5`，**0 是学生可拖到的标准档位**；`ArithmeticPage.tsx:130-144` 的切入守卫只在切换模式时置 `d = −1.5`，不阻止随后拖动）。

### 🔴 P0-3：递推页二阶递推在 Δ<0 时仍渲染「降阶等比等价式」

**文件**：`src/features/sequence/RecurrencePage.tsx:352-356`

```ts
if (recurrenceModelType === "second-order") {
  const delta = p_rec * p_rec + 4 * q_rec;
  const r1 = delta >= 0 ? (p_rec + Math.sqrt(delta)) / 2 : p_rec / 2;   // ← Δ<0 时硬赋值 p/2
  const r2 = delta >= 0 ? (p_rec - Math.sqrt(delta)) / 2 : p_rec / 2;
  return `a_{n+2} = ${p_rec} a_{n+1} + ${q_rec} a_n \iff a_{n+2} - (${r1.toFixed(2)}) a_{n+1}
          = (${r2.toFixed(2)})(a_{n+1} - (${r1.toFixed(2)}) a_n)`;
}
```

**复现参数**：二阶特征根法，`a₁ = −3, a₂ = −5, p = 1, q = −3` ⇒ **Δ = p² + 4q = 1 − 12 = −11 < 0**。

**实测（真渲染）**：

- 中屏顶部横幅照常输出：
  `a_{n+2} = 1a_{n+1} + −3a_n  ⟺  a_{n+2} − (0.50)a_{n+1} = (0.50)(a_{n+1} − (0.50)a_n)`
- **同一屏右侧**红字：`Δ = p²+4q < 0，降阶等比不适用`（`RecurrenceSecondOrderScene.tsx:98-99` 守卫已生效，中屏几何部分正确隐藏）

**等价式本身不成立（数值反证）**：

```
a_{n+2} = a_{n+1} − 3a_n，b_n := a_{n+1} − 0.5a_n
a₁ = −3, a₂ = −5 ⇒ a₃ = −5 − 3(−3) = 4
LHS = a₃ − 0.5a₂ = 4 + 2.5 = 6.5
RHS = 0.5 · (a₂ − 0.5a₁) = 0.5 × (−3.5) = −1.75
6.5 ≠ −1.75  ⇒  ⟺ 号两侧不等价
```

**性质**：09-21 的 P0-2 修好了"中屏几何"，但**顶部等价式是另一个出口，漏了同一守卫**——修复不彻底。同屏自相矛盾（一边说"不适用"，一边给出等号）。
