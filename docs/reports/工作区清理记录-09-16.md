## 一、⚠️ 重要更正：`package.json` 的 audit 命令**并未悬挂**（未改动）

此前两轮记录（含工作区盘点）均称 `audit` / `audit:strict` / `audit:update-baseline` 指向不存在的 `.agents/skills/math-page-audit/scripts/audit_page.mjs`，"必要报错"。

**该结论错误，来源是一次被误读的 shell 探测**：

```bash
ls -d .agents .claude .codebuddy .workbuddy skills 2>/dev/null || echo "(均不存在)"
```

`ls` 在多参数下**只要有一个路径不存在就整体失败**，`2>/dev/null` 又把错误吞掉，`||` 分支被触发 → 被读成"`.agents/` 不存在"。

**实测事实**：

| 核验项 | 结果 |
|---|---|
| `.agents/skills/math-page-audit/` | 存在，15 个文件（`SKILL.md` + 3 references + 11 scripts） |
| `scripts/audit_page.mjs` | 存在（9880 B），且支持 `--strict`、`--update-baseline` |
| `node .agents/skills/math-page-audit/scripts/audit_page.mjs` | **退出码 0**，扫描 683 文件，存量错误 243 / 增量 0 |
| `package.json` 全部 14 条 script 目标 | **全部存在**（含 vitest/tsc/eslint/electron-vite/husky 与 `src/math`、`src/math3d` 等目录） |

→ **`package.json` 零改动**。若按原错误结论"修掉"这三条命令，将删除一套可正常运行的静态门禁工具（含 `src/test/auditEngine.test.ts` 引擎测试所依赖的 skill）。**此为该错误结论未被执行的关键。**

**教训**：判断路径存在性必须逐条判断（`for` 循环 + `[ -e ]`），不可用多参数 `ls` 配合 `||`；被 `2>/dev/null` 吞掉的错误不能作为"不存在"的证据。
