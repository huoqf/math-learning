### P0-1　`/function-symmetry` 秒杀口诀把周期系数写错（T=4a 应为 T=2a）

- **位置**：`src/data/builders/funcProperties.ts:966`（gaokaoPoints 第 3 条，`importance: "gaokao"`）
- **原文**：`f(x+a) = \frac{1-f(x)}{1+f(x)} \implies T = 4a`
- **验算**（令 u = f(x)）：
  ```
  f(x+a)   = (1-u)/(1+u)
  f(x+2a)  = (1 - f(x+a))/(1 + f(x+a))
           = ((1+u) - (1-u))/((1+u) + (1-u))
           = (2u)/(2) = u = f(x)
  ⇒ T = 2a
  ```
  真正给出 **T = 4a** 的是另一支 `(1+f)/(1-f)`：`u → (1+u)/(1-u) → -1/u → u`（第 3 步倍化后回到 u，故 T = 4a）。
- **结论**：该口诀把「公式」与「周期」配错。**学生背下来必错。** 同一行前三条（`-f(x)`、`1/f(x)`、`-1/f(x)` 均 T=2a）**逐条验算正确**，仅第四条错。
- **可达性**：`/function-symmetry` 任一「周期」子模式的考点区即显示 ⇒ **路由可达、学生可见**。
- **修法**：把 `T = 4a` 改为 `T = 2a`；或把公式换成 `\frac{1+f(x)}{1-f(x)}` 保留 4a。

### P0-2　`/derivative-shift` 极值点偏移推导链伪造等式（结论对、推导假）

- **位置**：`src/data/builders/derivativeShift.ts:175`（定理 note）与 `:313`（reasoningSteps[2].latex）
- **原文**：`F(x_1) < 0 \implies f(x_1) < f(2x_0 - x_1) = f(x_2) \implies x_1 + x_2 > 2x_0`
- **验算**（用该页默认模型 `xe_neg_x`、k = 0.25，x₀ = 1）：
  ```
  x₁ ≈ 0.3575   (0.3575·e^-0.3575 = 0.2501 ✓)
  x₂ ≈ 2.1533   (2.1533·e^-2.1533 = 0.24996 ✓)
  2x₀ - x₁ = 1.6425 →  f(1.6425) = 1.6425 · 0.19352 = 0.31787
  f(x₂) = k = 0.25
  ⇒ f(2x₀-x₁) = 0.3179 ≠ 0.25 = f(x₂)   ← 等号不成立
  ```
- **正确链**：`F(x₁)<0 ⇒ f(x₁) < f(2x₀−x₁)`，代入 `f(x₁)=f(x₂)` ⇒ `f(x₂) < f(2x₀−x₁)` ⇒（f 在 (x₀,+∞) 严格递减）`x₂ > 2x₀−x₁` ⇒ 结论。
- **自证**：同页 `:182` 的高考要点写的是 **正确版**（"③ 结合单调性等价转化 $f(x_2) < f(2x_0 - x_1)$"）⇒ 这是核对后可确定的错误，而非风格差异。
- **危害**：极值点偏移是本页压轴结论，推导链是唯一采分载体；学生照抄这条链会被判"等号不成立"。

### P0-3　`/derivative-endpoint` 中屏顶部放缩不等号方向随阶数写反（与右屏自相矛盾）

- **位置**：`src/features/derivative-endpoint-taylor/DerivativeEndpointTaylorAnimation.tsx:146`（ln）、`:148`（sin）—— 该串由 `:340` 的 `<KatexFormula>` 渲染在页头公式条。
- **原文**：无论阶数一律写 `\ln(1+x) \le P_n(x)`、`\sin x \ge P_n(x)`、`\cos x \ge P_n(x)`。
- **默认阶数**：`taylorOrder` 初值 = **2**（`:46`）。
- **验算**（x = 0.5）：

  | 基底 | 阶 | P_n(0.5) | 真值 | 页面断言 | 实际关系 | 判定 |
  |---|---|---|---|---|---|---|
  | ln(1+x) | 2（**默认**） | 0.375 | 0.405465 | `ln ≤ P₂` | `ln ≥ P₂` | ❌ **方向反** |
  | sin x | 2（**默认**） | 0.5 | 0.479426 | `sin ≥ P₂` | `sin ≤ P₂` | ❌ **方向反** |

### P0-6　`/function-zero` 二分法：区间标签与定理指数口径混用两套约定

- **位置**：`src/math/function.ts:803-836`（返回）、`src/data/builders/funcZero.ts:51-56 / 60-62 / 68-70 / 93-99`（展示）
- **机制（读码即定）**：循环体在**每次折半之前**先 `steps.push({left, right, mid})`，再更新 `left/right`。故 `steps[k−1]` 保存的是 **I_{k−1}**；`currentStep = steps[steps.length−1]` 返回 **I_{k−1}**，`errorBound = |I_{k−1}|/2 = (b−a)/2^k`。
- **手工验算**（cubic，m=1、n=2、maxSteps=3，真根 ≈ 1.5214）：

  | 迭代 | 起始区间 | 中点 | 折半后 |
  |---|---|---|---|
  | 1 | I₀=[1,2] | 1.5 | I₁=[1.5,2] |
  | 2 | I₁=[1.5,2] | 1.75 | I₂=[1.5,1.75] |
  | 3 | I₂=[1.5,1.75] | 1.625 | I₃=[1.5,1.625] |

  面板实际显示：区间 `[1.5000, 1.7500]`（= I₂，长 0.25），却标 `[a_3, b_3]`；根 `1.6250` 标 `c_3`；误差 `≤ 0.1250`。
- **两处自相矛盾**：
  1. 定理 `:95` 写 `|b_k − a_k| = (b−a)/2^k = 1/8 = 0.125`，而**显示的区间长度是 0.25**（差一个 2 的因子，因为显示的是 I_{k−1}）。
  2. 定理同一行写 `|x^* − c_k| ≤ (b−a)/2^{k+1} = 1/16 = 0.0625`，但实现里 `c_k` = **第 k 次取的中点**（I_{k−1} 的中点），其真实误差界是 `(b−a)/2^k = 0.125`。实测 `|1.5214 − 1.625| = 0.1036 > 0.0625` ⇒ **面板展示的数值直接违反同屏定理**。
- **根因**：混用了两套 `c_k` 约定 —— 实现用"第 k 个中点"（约定 B，界 2^k），定理写的是"第 k 次折半后区间 I_k 的中点"（约定 A，界 2^{k+1}）。
- **修法（二选一，三处必须同口径）**：㈠ 保持约定 B ⇒ 定理指数改为 `2^k`、区间行改标 `[a_{k-1}, b_{k-1}]`；㈡ 改为约定 A ⇒ `function.ts` 返回 `I_k`、根取 `mid(I_k)`、定理保持不变。

## 十、结论摘要

1. **数学本体质量高**：切线放缩、隐零点、极值点偏移、双切线卡位、量词判据、对称周期、初等函数性质等**大类结论经逐点验算全部正确**；问题集中在**推导链书写**与**语义方向**两类，共 6 条 P0，全部为**小改动可修**。
2. **中屏工程一致性优秀**（坐标范式/退化态/断线处理），但**视口裁切**是系统性缺陷（5 个页面），且拖拽未接入项目已有的 `paramClamp` SSOT。
3. **最重的结构性问题是课标归位**：必修一的指数/对数页面混入选必二的导数内容（含求导推公式），且零拓展标注 —— 这既是合规问题，更是**教学时序倒置**问题，建议迁移而非补标注。
4. **最重的覆盖缺口是导数基础运算**：五大求导公式/四则运算法则/复合求导/优化问题整块缺失，建议单独立项补页。
5. **提分强项是压轴通法层**（5 页），其"卷面合规路径"的写法可直接作为其余页面的范式。
