## 2. 门禁体系根本性修复（报告第一部分）

### 2.1 【P0】审计覆盖面缩水 —— 假性"零违规"

**根因**：`audit_page.mjs` 默认目标硬编码为 `src/features`；`runner.mjs` 仅在目标**恰好等于** `src/features` 时才补扫 `src/math`、`src/math3d`。于是 `src/data`（140 文件 / 556 error）与 `src/components` 从未进入门禁。

**修复**：
- `audit_page.mjs`：默认扫描目标 `src/features` → **`src`**（全量）。
- `runner.mjs`：`walkDirectory` 排除 `__tests__/` 目录与 `*.test.ts(x)` 文件。测试文件不是上屏页面；且审计引擎**自身的用例**会以字符串字面量故意写入违规样例（如 `BrowserRouter` 夹具），纳入扫描会造成**稳定误报**。
- 结果：502 文件 → **670 文件**（排除测试后的真实有效集合）。

### 2.2 【P1】存量违规治理 —— 引入"基线"机制，strict 只拦增量

**根因**：全量扫描一旦开启，历史存量会立即红灯，无法落地。

**修复**：
- `audit_page.mjs` 新增 **`--update-baseline`**，以 `(文件::规则::类型::级别)` 为键写入 `.audit-baseline.json`。
- 审计输出**分账**：`存量错误（基线豁免）` 与 `本次增量错误` 分开计数；`--strict` **仅当增量 > 0 时非零退出**。
- `package.json` 新增脚本 `audit:update-baseline`。
- 生成基线：**136 个键 / 497 处违规**（402 error + 95 建议）。
- 实测：`npm run audit:strict` → `存量错误 402 处（基线豁免），本次增量错误 0` → **exit 0**。

### 2.3 【P1】规则适用范围过宽 → 海量误报

**根因**：`left/param-label-format` 未区分 `ParamMeta.labelFormula`（参数标签）与 `ParamMark.labelFormula`（滑块刻度，取值本身如 `"0"` / `"1"`），命中的 347 处绝大多数是刻度噪音。

**修复**：`rules/left-panel.mjs` 改为**按作用域判定**——仅约束 `ParamMeta`，跳过 `marks: [...]` 内的 `value:` 刻度；347 处噪音收敛为真问题。

### 2.4 【P1】门禁完全不校验数学正确性与学段边界（核心缺口）

**修复（三层防线）**：

1. **新增超纲术语门禁** `discipline/no-beyond-syllabus-terms`（`rules/discipline.mjs`）
   黑名单：洛必达 / 麦克劳林 / 泰勒 / 琴生 / 凹凸 / 极点极线 / 克拉默 / 外积 / 叉积 / 夹逼 / 等价无穷小 / 上确界 / 下确界 / 紧致 / 无穷级数 / 数列极限 / 特征方程 / 马尔可夫链 / 卡方分布 / 概率密度函数 / 微元 / 定积分 / 极坐标 / 参数方程。
   判据：命中且**未声明** `importance: "extend"` 或未带「拓展 / 选学」徽标 → **error（阻断）**；已声明拓展 → **warning（提示）**。
2. **知识树学段边界契约测试**（`src/data/knowledgeTree.test.ts`）
   - `importance:"extend"` 的节点，标题必须带「拓展 / 选学 / 超出课标 / 竞赛」语义；
   - `module` / `chapter` 含"拓展"字样的节点，`importance` 必须为 `"extend"`；
   - `syllabus.status ≠ "正文"` 时 `importance` 必须为 `"extend"`；
   - 正文节点不得标注"超出课标"。
3. **硬编码色值补齐**：`rules/style-tokens.mjs` 的 `no-hardcoded-hex` 增补 `\color{#RRGGBB}{...}`（LaTeX 内联）检测；全库 56 处硬编码六角色统一改为 `${MATH_COLORS.*}`。
