## 零、结论摘要

1. **边界问题的根因不是"个别条目写错"，而是内容与册次之间没有机器约束。**
   `src/data/syllabus.ts` 已经为每个节点推导出唯一册次（`resolveSyllabus()` → `{book, status}`），
   但 `builders/` 产出的所有文本**完全不受该册次约束** —— 所以"必修一页面讲导数"这件事
   在结构上是**不可能被现有门禁发现**的（本轮 `audit:strict` 扫描 725 文件、0 error 已证实）。

### 3.2 移入类（B2/B7/C3/C6/C7）

**目标页：`/derivative-transcendental`（`derivativeTranscendental` feature）的 `chain` 模式。**

选择理由（读码得到，非推测）：
- `chain` 模式的主题本来就是**"互为反函数"**——`transcendental.ts:321-331` 的链式放缩定理
  前置项第一条即"`e^{x-1}` 与 `\ln x+1` 互为反函数"，与 `a^x` / `\log_a x` 的反函数关系同源；
- 反函数公切线临界 `a = e^{1/e}` 本质上就是**链式放缩在一般底数 `a` 下的临界推广**，
  放在 `chain` 模式下是同一条教学线的自然延伸，不需要新造主题。

具体落地（3 项）：
1. 新增预设 `inverse_tangent_critical`（建议 paramKey 走 `a`，取值集中在 `1.4 ~ 1.5`）——
   展示 `1 < a < e^{1/e}` 两交点 / `a = e^{1/e}` 相切于 `(e,e)` / `a > e^{1/e}` 无交点 三态；
2. 新增 theorem「反函数公切线临界定理」（`level:"core"`），latex 与前置项直接沿用
   `funcExpLog.ts:586-595` 的三态分类（该条本身数学正确，无需改写）；
3. 新增 `quantities` 量「相切临界底数 `a_c = e^{1/e}`」与「两曲线交点情况」，
   文案沿用 `funcExpLog.ts:369-372`（`a_c` 三态就任一数值参数而言是**不变量**，
   符合项目的 `isInvariant` 语义，建议同时标 `isInvariant: true` + `invariantNote`）。

> 中屏：`TranscendentalScene` 的 `chain` 模式已画 `e^{x-1}` 与 `ln x+1`；新增该预设后

### 4.3 各页内容设计要点

**① `/derivative-formulas` 基本初等函数导数公式表**
- math 层：`BASIC_DERIVATIVE_TABLE`（`C`、`x^α`、`a^x`、`e^x`、`\log_a x`、`\ln x`、`\sin x`、`\cos x`）
  + `evalDerivative(model, x, params)`；x₀ 拖拽域一律走 `utils/paramClamp.ts`（与批次二同一 SSOT）。
- 中屏：表格行选中 → 坐标区同步画出 `f(x)` 与 `f'(x)` 两条曲线，在可拖点 `x₀` 处同时读出
  `f(x₀)` 与 `f'(x₀)` 并画出 `f(x)` 的切线。
- 教学关键点（本页的核心价值）：`(\ln x)'=1/x` 与 `(\log_a x)'=1/(x\ln a)` 的差别；
  `(e^x)'=e^x` 的自相似性（**画图比背表有效**）；`(x^α)'=αx^{α-1}` 在 `α=1/2, −1` 时的形态。
- 右屏：`quantities` 放 `f(x₀)` / `f'(x₀)` / 切线方程；`theorems` 放公式表本体；
  `reasoningSteps` 三步（识别函数类型 → 套对应公式 → 代入求值）。

**② `/derivative-operations` 导数的四则运算**
- math 层：和差 / 积 / 商法则 + 两个可调因式（`u`、`v` 从预置库里选，`v` 支持 `ax` 型含参）。
- 中屏（**本页必须画的一笔**）：同一坐标系里画 `(uv)` 与 `(uv)'`，**再加一条警示色的 `u'·v'`**
  —— 直接用图形证伪 `(uv)' \ne u'v'`。这是本页唯一不可替代的教学动作。
- 右屏：`reasoningSteps` 三步（拆成 u、v → 套法则展开 → 化简 + 代点求值）；
  `warnings` 常驻提示"商的法则分子是 `u'v − uv'`，顺序不可反"。

**③ `/derivative-chain` 简单复合函数求导 `f(ax+b)`**
- **必须在页内显式区分于 `/composite`**（后者是必修一"复合函数**概念**"）：
  本页标题/徽标须写明"复合函数的**求导**法则"，在 `prerequisites` 里同时挂
  `know-derivative-formulas`（本页依赖），并避免复用 `/composite` 的任何文案。
- math 层：`chainRule(f, g, x)` + 4 个模型 `(ax+b)^n` / `e^{ax+b}` / `\ln(ax+b)` / `\sin(ax+b)`。
- 中屏：**三层并列**——内层线性 `u=ax+b` 的数轴、外层 `y=f(u)` 的图象、复合 `y=f(ax+b)` 的图象，
  用三条同步点亮标记把 `x → u → y` 串起来。
  （这正是审查报告 §P1-H 指出的"中间变量轴缺失"问题，新页要一次做对。）
- 右屏：结论写 `y' = f'(u)\cdot a`，措辞按课标用"复合函数的求导法则"，
  **不要**引入"链式法则/Chain Rule"这类外文术语。

**④ `/derivative-optimization` 生活中的优化问题**
- math 层：4 个模型（面积 / 体积 / 成本 / 利润），每个带**由实际意义给出的定义域**。
- 中屏：几何模型直接画图形（如边长可拖的矩形围栏、可拖半径的圆柱罐体），
  并画出目标函数在可行域上的曲线与极值点。
- 右屏：标准五步 `reasoningSteps`（设变量 → **建函数并写明定义域** → 求导 → 求驻点并与端点比较 → 作答带单位）；
