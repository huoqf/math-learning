# 高中数学可视化页面质量与新高考教学审计规范 (Math Page Audit Protocol)

> 本技能为高中数学（代数函数、解析几何、平面向量、立体几何、概率统计等）页面质量与教学严谨性的**通用审查准则与 SOP 指南**。
> 适用于全学科所有专题页面的新建、重构与质量核查。

## 📐 一、数学严谨性与新高考思维审计（代数与定理层）

### 1.1 学术符号与代数规范（高考阅卷级标准）
- **符号纯正性**：严格使用统编教材规范符号（向量带箭头 $\vec{a}, \vec{b}$，点标为大写字母 $A, B, P$，参数为 $k, b, a, b, c, \lambda, \mu, x_0, y_0$），**严禁将程序员变量名（如 `xa, ya, det, lambdaA, vecA`）暴露在界面上**；
- **代数标准消元（杜绝 `+ -1.0` 瑕疵）**：
  - 正负号规范：`+ -` 必须自动转化为 `-`（如 `x - y - 2 = 0`，严禁 `1.0x + -1.0y + -2.0 = 0`）；
  - 系数 1 与 0 项规范：系数为 1 省略数字（$1x \to x$），系数为 0 则整项消去（$0x \to$ 省略）；
- **KaTeX 动态色彩 Token 指令绑定（铁律 4C）**：
  - 严禁在公式中硬编码 Hex（如 `\color{#EF4444}`）；
  - 必须使用动态 Token 指令绑定参数色彩：`\color{${MATH_COLORS.paramPrimary}}{a}x^2 + \color{${MATH_COLORS.paramSecondary}}{b}x`。

### 1.2 定理适用前提显式完备
右屏 `theorems` 中每一个公式必须显式给出其适用的数学前提 `condition`（如：截距式标明 $a \neq 0 \text{ 且 } b \neq 0$；基本定理标明 $\vec{e}_1, \vec{e}_2 \text{ 不共线}$；点斜式标明“斜率存在”）。

### 1.3 多表征与形式完备性（杜绝漏项）
数学概念或几何对象若在课标中存在多种等价表征，必须支持全量探究与参数调节：
- **代数/解析表征完备**：直线 5 种方程形式、圆锥曲线标准/参数方程、导数切线与同构等；
- **几何/向量表征完备**：向量运算的平行四边形法则（共起点）与三角形法则（首尾顺次相接，差向量方向为从减数指向被减数）、基底分解与投影轴；
- **离散/连续表征完备**：数列通项与前 $n$ 项和、概率分布列与连续密度曲线等。

### 1.4 新高考解题思维提炼与临界分类讨论
- **大招思维提炼（`gaokaoPoints`）**：提炼几何代数速算法（公共弦作差法、弦心距勾股法、极化恒等式、点差法中点弦等）与动系不变量（恒过定点、对称极值）；
- **分类讨论响应（`warnings`）**：参数处于退化临界时实时触发警示（除零/斜率不存在/基底共线/判别式 $\Delta \le 0$/半径 $r \le 0$）。

## 🎛️ 二、左屏控制台交互与教学引导规范（控制层）

### 2.1 单向操作动线（严格从上至下）
```
1. 核心专题模式 (SelectGrid 2x2 或 2+1)
   └── 2. 典型构型预设 (SelectGrid 2x2，首项固定为 free 自由探究)
         └── 3. 模式特性/锁定量配置 (可选开关)
               └── 4. 参数与坐标调节 (ParamControl + 重置按钮，按 group 聚合)
                     └── 5. 教学引导与探究提示 (置于最底部辅助区)
```

### 2.2 自适应排版与参数对象化
- **自适应选列**：短文本（$\le 5$ 字）采用 2 列网格；长描述/复杂分式（$> 6$ 字）采用单列全宽（`fullWidth: true`），杜绝 `...` 省略号截断；
- **声明式 `paramMeta` 100% 注册完备性**：
  - 凡在 `paramConfigs` 中引用的参数 key 必须 100% 在 `paramMeta` 中注册（严禁漏配导致滑块丢失）；
  - 数学定义域严格保护（圆半径 $r > 0$、椭圆 $a > b > 0$）；
  - 在 `marks` 中标明退化临界点（如 $A=0$ 水平线、$B=0$ 铅垂线标为 `variant: "critical"`）；
- **参数对象化聚合**：同一几何对象（如定点 $P_0(x_0, y_0)$、向量分量、复数实虚部）配置相同 `group` 属性，主控动参数在上，底模几何参数在下。

### 2.3 教学引导卡片规范（置于底部辅助区，不阻断调参动线）
- **摆放位置**：必须置于左屏**最底部**（在 `ParamControl` 之后），杜绝插在模式选择与滑块中间阻断调参视线；
- **双要素架构**：
  1. 【**基础条件**】：清晰列出当前模型的前提假设与约束（$\le 1$ 句）；
  2. 【**探究问题**】：提出 1~2 个启发性核心思考题，引导学生带着问题去拖拽；
- **职责隔离**：教学引导仅作轻量级启发，**严禁堆砌右屏专属的定理推导、完整公式证明或高考考点**（100% 归位右屏 `MathPanel`）。

## 🖼️ 三、中屏数形结合与作图避坑防火墙（视觉与渲染层）

### 3.1 高中数学作图范式与动态认知
- **虚实线分工**：主体几何图形/主向量/函数曲线为**实线**；投影线/平行辅助线/延长线/不可见棱为**虚线（`4,4` / `6,4`）**；
- **几何符号规范**：垂直处必带直角折线标尺 ∟ 与垂足 $H$；空间角/平面角必配标准角弧与符号（$\alpha, \beta, \theta$）；
- **标尺防畸变**：直角符号 $\perp$ 边长固定为 9~10px（严禁乘以 `fontScale` 导致 clamp 保护算出巨框）：`const size = Math.min(10, vLen * 0.35);`；
- **纯净坐标系**：`CoordinateGrid` 默认 `showGrid={false}`（纯白底色 + 清晰 $xOy$ 主轴，杜绝虚线方格网干扰）；
- **平滑演化**：动点滑动与极限逼近（如割线趋向切线、基底投影闭合）必须连续平滑，严禁闪烁跳跃。

### 3.2 标签排版与几何避让（彻底杜绝重叠与遮挡）
- **纯字母点标与微描边**：几何点仅标单字母（$A, B, C, P$），严禁在画布堆砌坐标数值；文字采用 `paintOrder="stroke" stroke="white" strokeWidth={3}` 微描边，严禁添加 `<rect>` 白底框遮断背后线条；
- **单源避让机制**：`InteractivePoint` 不传 `label`，所有点文本统一由 `avoidLabelOverlap` 调度，杜绝点内点外双重渲染重影；
- **相交对角线错位（`labelPositionRatio`）**：相交线段（如平行四边形和向量与差向量对角线在中心相交）严禁均在 $t=0.5$ 标注，必须分别置于 $t=0.8$ 与 $t=0.75$ 错开中心交点；
- **共线/平行图元法向分流（`getNormalOffset`）**：同一直线或方向相近的图元标签，必须通过法向算法分别偏移至两侧（$\pm 16\text{px}$）；
- **简练学术标号**：图形线段上仅标注精炼符号（如 $\vec{a}, \vec{b}, \vec{a}+\vec{b}, \vec{a}-\vec{b}$），严禁硬塞长串方程字符串（如 `s = λa + μb`）。

### 3.3 交互解耦与临界图元穿透
- **坐标解算一致性**：`InteractivePoint` 回调传出的已是数学坐标 `{ x, y }`，**严禁再次调用 `designToMath`**（避免二次缩放乱飞）；
- **拖拽预设解耦**：画布拖拽动点时自动将预设切回【自由探究】（`free`）并展开全量参数；
- **临界图元穿透**：相切时切点 $T$、半径 $CT$、直角标尺 ∟ 必须齐全；动系恒过定点时定点 $P_0$ 必须高亮标注。

## 📊 四、右屏数学看板同步与 5 步审计 SOP（验证层）

### 4.1 四项看板同步合格标准
- **数学量（Quantities）**：首项量化数据必须与左屏选中的模式/预设强关联，实时反映核心代数指标；
- **定理（Theorems）**：左屏选中的探究模式，其对应的核心定理必须设为 `level: "core"` 置顶展示；
- **考点（GaokaoPoints）**：提炼与当前模式直接对应的高考解题模型与实战秒杀方法；
- **警示（Warnings）**：参数处于临界状态时动态弹出，正常时自动隐藏。

### 4.2 静态检索特征码（CLI 诊断）
```bash
# 1. 检查是否存在拖拽二次转换 BUG
grep -rn "onDrag.*designToMath" src/features/

# 2. 检查是否存在非标准 LaTeX 负号拼接
grep -rn "\+ \-" src/features/

# 3. 检查是否有全量编译与类型错误
npm run build
```

### 4.3 标准化页面审计 5 步执行法（SOP）
1. **第 1 步【查大纲与数学完备度】**：确认核心概念多表征、定理推导与高考秒杀解法无遗漏，运算法则方向性正确。
2. **第 2 步【查左屏动线与排版】**：确认操作动线符合标准顺序，教学引导置于底部且仅含【基础条件】与【探究问题】，`paramMeta` 注册无遗漏，排版无 `...` 截断。
3. **第 3 步【查中屏图象与几何避让】**：测试相交线段与共线向量，确认文字无重叠、无长公式污染，直角标尺无畸变，临界图元齐全，拖拽自动切回 `free`。
4. **第 4 步【查右屏看板与色彩绑定】**：确认公式色彩 Token 绑定一致，右屏核心定理随左屏模式置顶跟随。
5. **第 5 步【全量工程构建】**：执行 `npm test` 与 `npm run build`，确保 `Exit code 0`，零类型报错与零警告。
