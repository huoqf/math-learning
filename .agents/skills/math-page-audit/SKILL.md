## 📐 一、数学严谨性与代数定理规范（代数与定理层）

### 1.1 学术符号与代数消元标准（高考阅卷级）
- **符号纯正性**：严格使用教材规范符号（向量 $\vec{a}$，点标大写字母 $A, P$，参数 $k, b, a, \lambda, x_0$），**严禁将程序员变量名（如 `xa, det, vecA`）暴露在界面上**；
- **代数标准消元**：正负号必须规范（`x - y - 2 = 0`，严禁 `+ -` 出现）；系数为 1 省略（$1x \to x$），系数为 0 整项消去；
- **KaTeX 动态色彩 Token 绑定（铁律 4C）**：严禁硬编码 Hex，必须使用 Token 指令：`\color{${MATH_COLORS.paramPrimary}}{a}x^2`；
- **全屏数学表达式 KaTeX 与 Unicode 渲染双轨规范**：
  - ❌ **严禁**在普通 JSX 字符串、TipCard 文字或 `description` 中裸写 LaTeX 源码（如 `"e^{x-1} \ge x"` 导致大括号 `{}` 暴露）；
  - ❌ **严禁**在 SVG `<SceneLabelGroup>`、`<text>` 或曲线点标签中直接传入带反斜杠与花括号的 LaTeX 源码（如直接传 `\sqrt{x}`、`\frac{1}{x}`、`x^3` 导致画布暴露源码）；
  - ✅ **SVG 画布内曲线/点标注必须使用标准 Unicode 数学字符**（如 `y = √x`、`y = 1/x`、`y = x³`、`y = x²`、`y = x`）或纯代数符号，复杂解析式一律归位右下角 `<SceneLegend />` 与左上角 `<KatexFormula />`；
  - ✅ **TipCard 与普通 UI 文本**：公式必须使用 `<KatexFormula formula="..." mode="inline" />` 渲染；`SelectGrid` 选项应保持纯净中文，严禁配置 `formula` 堆砌复杂公式。

### 1.2 定理前提完备与多表征覆盖
- **适用前提显式完备**：右屏 `theorems` 必须显式给出前提 `condition`（如：截距式 $a, b \neq 0$；向量基底不共线；斜率存在）；
- **多表征完备探究**：直线 5 种方程形式、圆锥曲线标准/参数方程、向量平行四边形/三角形法则等课标表征必须全量支持；
- **大招提炼（`gaokaoPoints`）**：提炼几何代数速算法（弦心距勾股法、极化恒等式、点差法、同构放缩等）；
- **分类讨论响应（`warnings` 与多临界解耦）**：退化临界（斜率不存在、判别式 $\Delta \le 0$、半径 $r \le 0$）实时警示；当模式包含多个子模型时（如定点相切 $a=1$ 与原点相切 $a=e$），Warning 判定必须按 `subMode` 分支解耦计算，杜绝单一阈值穿透。

## 🎛️ 二、左屏控制台交互与教学引导规范（控制层）

### 2.1 动线模式分类（因题制宜，拒绝教条化强塞）
- ⚠️ **拒绝教条化一刀切**：基础函数/单模型页面直接自由调参，严禁生硬堆砌“自由探索 vs 典型情景”选择器；仅在**存在高考特定题设构型、复杂几何/概率预设**时，才按需引入情景并控制参数的显示与隐藏（降维）。
- **A 类：单模型/基础代数函数页面（如一次/二次/幂指对三角基础曲线）**：
  `模式维度 (TabSwitcher) → 核心参数调节 (ParamControl) → 教学导引 (TipCard)`
- **B 类：多构型/高考预设/复合模型页面（如圆锥曲线特定构型、立体几何截面、条件概率与贝叶斯诊断等）**：
  `模式维度 (TabSwitcher) → 典型情景/预设 (SelectGrid，含 free 自由探索) → 参数调节 (按情景降维展开) → 辅助开关 → 教学导引`

### 2.2 典型情景下参数显示/隐藏控制（参数降维核心初衷）
- **情景预设的本质（参数降维与真实题设锁定，杜绝认知混乱）**：
  * **存在典型情景/预设时**（如几何正方体/焦点三角形，概率相互独立/三车间次品/罕见病筛查/马尔可夫传球）：**按题设约束锁定从属量，仅展示真题所需的核心自变量（0 到多个，杜绝机械写死 1 个）**：
    - 若题设完全确定（如定值验证、标准频数）：开放 0 个滑块，界面渲染【题设基准数据已锁定】提示卡片，引导学生看图与作答；
    - 若题设包含待探究变量（如倍增倍率 $k$、转移步数 $n$、切点 $x_0$、抽样容量 $n$ 与权重 $w$）：仅开放这几个核心自变量，隐藏被题设锁定的基准参数；
  * **自由探索（`free`）**：在有预设体系的页面中作为首选项，全量展开所有参数，满足高阶自主探索；
  * **三屏强同步铁律**：
    - 中屏几何拖拽动点时，系统**自动切回【自由探索】（`free`）**并展开全量参数；
    - 右屏 `MathPanel` 的【公式定理 `theorems`】与【高考要点 `gaokaoPoints`】**随二级情景 100% 动态特化置顶**（如选独立置顶乘法判定，选互斥置顶加法公式，选传球置顶不动点构造等比数列法）。

### 2.3 全学科参数分层动线与量化分组铁律（SSOT 强约束）
- **量化分组门禁（参数 $\ge 4$ 项 100% 强制配置 `group`）**：
  - 凡是单个页面或 `ParamMeta[]` 注册表中包含 **$\ge 4$ 个可调参数**，严禁平铺堆积，**必须在元数据中显式声明 `group` 字段**（如解析几何分为“直线系参数”与“圆锥曲线基准”；立体几何分为“核心动点与探究参数”与“长方体基准尺寸”；概率统计分为“试验条件与样本容量”与“先验概率分布”）；
- **核心探究动参数置顶动线铁律**：
  - 严禁将背景常数、静态几何尺寸平铺在面板最顶层；
  - **核心探究自变量（动点比例 $\lambda, \mu$、切点 $x_0$、斜率 $k$、动角 $\theta$、样本量 $n$）必须排在第一 Group 优先展示，静态底模尺寸（$a, b, c, R, r$ 等）统一沉底在后续 Group**；
- **参数映射完整性约束（禁漏传 group）**：
  - 各 `Animation.tsx` 中的 `mapKeysToConfigs` 必须解构并透传 `group: meta.group`，严禁在页面映射层遗漏导致分组失效；
- **自适应排版**：预设选项 $\ge 4$ 项时，优先采用 `columns={2}` 双列网格排版，移除不必要的 `fullWidth`，垂直高度压缩 50%，实现左屏免滚动。

### 2.4 参数命名三位一体与比值学术规范
- **参数标签“含义 + 代号 + 比值/色彩”三位一体**：
  - ❌ **严禁**孤立英文字母（如仅写 $a, b, k, x_0$ 造成认知障碍），严禁写了孤立字母又在下方塞一行口水话 `description`；
  - ✅ **动点分点比必须采用标准课标比值定义**：如 `\text{动点 } P \; \left(\lambda = \frac{BP}{BB_1}\right)`、`\text{动点 } Q \; \left(\mu = \frac{AQ}{AC}\right)`；
  - ✅ **代数/函数参数必须在 `labelFormula` 中融合含义与色彩**：`\text{切点横坐标 } \color{${MATH_COLORS.paramPrimary}}{x_0}`；
- **滑块刻度 `marks` 防撞车铁律**：
  - 轨道两端组件已自带 `min / max` 灰色端点数值；
  - ❌ **严禁**在两端数字上平铺 marks（导致轨道刻度文字与两端数字严重重叠重影）；
  - ✅ **仅**在数学分水岭/退化临界点（如 $a=0$、不可导点、$\Delta=0$、离心率 $e=1$、线段中点 $0.5$）配置单个 `variant: 'critical'` 的关键 mark；
- **反填鸭式留白审查（做减法）**：
  - `LeftPanelSection`：纯净主标题，**严禁堆砌无意义副标题 `subtitle`**（如“调节参数观察变化”）；
  - `SelectGrid`：采用纯净加粗中文名称，自解释选项**省略 `description`**，严禁配置 `formula` 堆砌复杂公式；
  - `ParamControl`：自解释参数**省略 `description`**，压缩垂直高度，让左屏紧凑自然。

### 2.5 教学引导卡片规范（标准高考题设双要素与防剧透铁律）
- **功能定位**：承载真实考题题设说明与核心设问，防止学生看不懂当前场景；
- **摆放位置**：必须置于左屏最底部，杜绝插在模式与滑块中间打断调参；
- **双要素架构与防剧透铁律**：
  ①【**初始条件**】（讲清几何/函数/概率背景与自变量参数化定义，如动点所在棱、截面构成、试验条件，公式用 `<KatexFormula>` 渲染）
  ②【**核心设问**】（**必须提炼为符合高中课标与高考真题风格的设问句**，如“求满足某条件的动点位置/二面角/最值”、“探究是否存在动点满足垂直关系”）；
  ❌ **严禁剧透设问**：严禁在 TipCard 设问中提前把配方解、极值点数值、方程根或定理结论当作问题写出（所有推导演算与结论 100% 归位右屏 `reasoningSteps` 与 `theorems`）。
- **职责隔离**：严禁在左屏堆砌定理证明或高考考点（100% 归位右屏 `MathPanel`）。

## 🖼️ 三、中屏数形结合与作图范式（视觉与渲染层）

### 3.1 高中数学作图范式与纯净视界
- **虚实线分工**：主体几何图形/主向量/函数曲线为**实线**；辅助线/投影线/延长线/不可见棱为**虚线**；
- **几何符号规范**：垂直处必带直角折线标尺 ∟ 与垂足 $H$（标尺边长固定为 9~10px，杜绝乘 `fontScale` 畸变）；空间角/平面角必配标准角弧与符号；
- **纯净坐标系与右下角图例**：`CoordinateGrid` 默认 `showGrid={false}`（纯白底色 + 清晰 $xOy$ 轴，杜绝方格网干扰）；全量函数方程、切线割线解析式、特征点坐标与阴影区释义必须统一置于中屏右下角 `<SceneLegend />`（半透明毛玻璃卡片）。
- **多曲线/基准对比模式 1-to-1 精确映射铁律**：
  - ❌ **严禁**在多曲线同屏对比时使用单一笼统项（如“5大基准族（紫色方块）”）代替实际绘制的多色曲线；
  - ✅ **`<SceneLegend />` 必须 1-to-1 完整列出中屏每条基准曲线的专属颜色与 KaTeX 公式**；
  - ✅ **当前选中的基准曲线在中屏直接加粗高亮（粗实线），其余为细虚线，严禁额外绘制第二层同轨主曲线造成重影与色彩冲突**；动点 $P$ 颜色必须与当前聚焦基准曲线颜色 100% 动态同步。

### 3.2 点标规范与几何避让（杜绝浮点数与重叠遮挡）
- **点标学术化（严禁浮点坐标与长串方程堆砌）**：
  - ❌ **严禁**在画布内手写 `<text>` 渲染随拖拽跳动的浮点数字符串（如 `P(0.7, 2.01)`）或长串解析式；
  - ✅ **必须**使用 `<SceneLabelGroup />` 渲染纯代数符号（如动切点 $P$ 或 $P_0$，交点 $P_1, P_2$，中点 $M$，拐点 $I$，极值点 $E$），精确数值与方程 100% 归位右下角 `SceneLegend` 与右屏看板；
- **智能避让与微描边**：`InteractivePoint` 不传 `label`，所有点文本统一由 `<SceneLabelGroup />` 自动执行 8 向防重叠碰撞分流与白底微描边，严禁添加 `<rect>` 白底框遮断线条；
- **相交与共线图元分流**：相交线段使用 `labelPositionRatio`（如 0.8 与 0.75）错开中心交点；共线/平行图元使用 `getNormalOffset` 沿法向两侧分流。

### 3.3 交互解耦与 1-to-1 拓扑同步
- **坐标解算一致性**：`InteractivePoint` 回调已是数学坐标，**严禁再次调用 `designToMath`**（避免二次转换乱飞）；
- **拖拽预设解耦**：画布拖拽动点时自动切回【自由探究】（`free`）并展开全量参数；
- **预设-中屏拓扑 1-to-1 强同步**：左屏每一项典型预设（如平移变体、二次放缩、相切临界），中屏 `Scene.tsx` 必须有对应的数学方程、差值阴影或特征图元独立分支，杜绝“预设改了参数而中屏拓扑未变”的假同步；
- **图层从属联动闭环**：关闭任一父级几何结构（截面、投影、辅助面/线、切接球等）时，其派生的专有从属图元（交点、垂足、特征中心、直角标尺、角弧等）必须 100% 同步隐藏，严禁孤立悬浮遗留。

## 📊 四、右屏看板同步与 CLI 门禁 5 步审计 SOP（验证层）

### 4.1 右屏因课型与学科分支特化规范（拒绝一刀切与物理仪表盘）

> ⚠️ **杜绝教条化一刀切**：右屏必须根据**课型属性（基础概念 vs 高考专题）**与**分支学科特点**进行差异化装配，严禁脱离课型强塞“三步推演链”，严禁残留“物理浮点仪表盘”。

#### 1. 两大课型分层装配矩阵
| 课型分类 | 适用场景 | 右屏认知动线与核心载体 | 严禁项 |
| :--- | :--- | :--- | :--- |
| **A 类：基础概念建构课** | 指对幂基础函数、三角函数、集合Venn、复数几何意义、立体几何基本概念 | `[临界警示] → [核心概念与定义(Theorems)] → [基本性质(单调/奇偶/周期)] → [特殊定点与特征解(Quantities)]`<br>• 重在**建立数学定义、符号表征与性质直观** | ❌ 严禁初学阶段生搬硬套“高考解答题推演链”；<br>❌ 严禁堆砌无意义的连续浮点采样点。 |
| **B 类：高考专题与大题模型课** | 圆锥曲线定点定值、导数同构与极值点偏移、进阶切接球、空间角大题、全概贝叶斯诊断 | `[临界警示] → [高考破题三步推演链(ReasoningSteps)] → [核心定理模型(Theorems)] → [高考通法与考点(GaokaoPoints)] → [特征量与不变量(Quantities，置底附录)]`<br>• 必须提供**带参数动态代入的解题推演**与 **`🌟 定值不变量`** 徽章 | ❌ 严禁退化为仅罗列数字的静态表格；<br>❌ 严禁丢失高考评分采分点提示。 |

#### 2. 五大数学分支学科特征量与载体规范
- **代数与基础函数**：聚焦**定义域、值域、单调区间、奇偶性、周期性、渐近线方程与必过定点**，严禁展示无关浮点坐标；
- **导数与微积分**：聚焦**切点横坐标 $x_0$、驻点方程、单调性区间讨论表、极值点偏移、同构放缩不等式与恒成立充要条件**；
- **平面向量**：聚焦**向量坐标 $(x, y)$、基底分点比 $\lambda, \mu$、平行四边形分解、极化恒等式与模长最值**；
- **立体几何与空间向量**：聚焦**空间几何线段代号（如 $PA=a, CA=b$）、射影降维、球半径公式、法向量与空间角精确值**；
- **解析几何**：聚焦**离心率 $e$、斜率截距 $k, m$、联立判别式 $\Delta$、韦达代数核、弦长面积与定点定值不变量**；
- **概率与统计**：聚焦**抽样容量 $n$、先验条件概率、完备事件划分、分布列、期望方差与卡方独立性检验**。

#### 3. 三屏符号与色彩一致性对账（SSOT 强约束）
> 审查每一个页面时，必须核对下述《三屏符号映射对照表》：
1. **左屏滑块标签**：必须包含具体的数学/几何物理代号（如切点 $x_0$、几何棱长 $PA=a$、离心率 $e$），严禁使用“边1”、“长”等脱离题设的代号；
2. **中屏几何与曲线**：所绘制的线段端点、切线切点、向量箭头必须与左屏代号 1-to-1 对应；
3. **右屏推导代入**：推演链 `reasoningSteps`、定理 `theorems` 必须直接代入中屏与左屏相同的代号；
4. **色彩三位一体**：主控参数 `paramPrimary`（红）、从属参数 `paramSecondary`（橙）、高维参数 `paramTertiary`（绿）在三屏必须绝对同色；
5. **空间几何图元完整度**：长方体必须标齐底面四顶点 $A, B, C, D$ 与体顶点 $C_1$，正棱锥标齐顶点 $S$、底面中心 $O_1$、底面角点 $A$ 与侧面中点 $M$，圆柱标齐上下底圆心 $O_1, O_2$ 与半径端点 $A_1$；严禁中屏只有孤立中心点导致学生找不到对应边；
6. **推演链字段严格规范**：`reasoningSteps` 必须使用 `{ step, title, detail, latex, rubric }` 标准字段，严禁误用 `description` 导致测试断言失败或渲染排版截断。

### 4.3 标准化页面审计 5 步执行法（SOP）
1. **第 1 步【定课型与学科边界】**：
   - 明确是 **A 类基础概念课**（重在定义定理性质、直观探索，右屏严禁生塞解答题推演链）还是 **B 类高考专题课**（重在解答题三步推演链、母题大招、秒杀考点、定值不变量）；
   - 确认核心概念多表征与定理前提条件完备。
2. **第 2 步【查左屏动线与三屏对账】**：
   - **参数分组与动线审查**：核查当前参数是否 $\ge 4$ 个，若 $\ge 4$ 个是否已强制通过 `group` 进行对象化分层；核心动自变量（$\lambda, \mu, x_0, k$ 等）是否置顶优先呈现，静态底模尺寸是否沉底；检查 `mapKeysToConfigs` 是否透传了 `group: meta.group`；
   - **参数代号规范**：检查参数命名是否符合“含义 + 代号 + 比值/色彩”三位一体，动点参数是否标清比值定义（如 $\lambda = \frac{BP}{BB_1}$）；
   - **三屏符号 SSOT 对账**：核对左屏参数代号、中屏图元线段与右屏推导代号 100% 一致；
   - **TipCard 设问规范**：检查是否落实标准双要素（初始条件 + 核心设问），设问是否为探究句，严禁提前剧透解题过程与最终极值。
3. **第 3 步【查中屏图象与作图标注】**：运行 CLI 门禁命令，确认无浮点坐标堆砌、无文字重叠，曲线方程就近标齐，拖拽自动切回 `free`。
4. **第 4 步【查右屏看板与色彩绑定】**：确认公式色彩 Token 绑定一致，A 类课呈现定义域/单调性/特殊解，B 类课动态代入当前参数并提供评分采分点提示。
5. **第 5 步【全量工程构建与契约测试】**：运行 `audit_page.mjs`，执行 `npx tsc -b` 与 `npm test`，确保全套单测与类型检查 `Exit code 0`。
