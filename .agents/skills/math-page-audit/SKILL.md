## 📐 一、高中数学教学需求与新高考考点审计

### 1.1 形式与定理完备度（杜绝漏项）
- **解析几何全家桶**：
  - **直线方程**：必须完整涵盖 5 种形式（一般式、斜截式、点斜式、截距式、两点式），且均可自由调节。
  - **圆与圆系**：圆的标准方程、一般方程、点线圆位置关系、两圆公共弦/根轴、内外公切线。
  - **圆锥曲线**：焦点、准线、通径、离心率、渐近线、焦点三角形、参数方程。
- **函数与导数全家桶**：
  - 切线方程（切点在曲线上 vs 过曲线外一点）、单调区间与极值点、零点存在性、导数同构与放缩。

### 1.2 新高考解题大招与核心思维呈现
右屏 `gaokaoPoints` 必须提炼高考实战秒杀思维，杜绝单纯照抄教材概念：
- **作差法速算**：两圆方程相减即得相交弦/根轴方程 $C_1 - C_2 = 0$。
- **勾股弦长法**：直线与圆弦长优先利用弦心距 $L = 2\sqrt{R^2 - d^2}$，避免联立二次方程求交点。
- **分离参数法求定点**：含参直线 $(A_1+\lambda A_2)x + (B_1+\lambda B_2)y + (C_1+\lambda C_2) = 0$ 整理为 $L_1 + \lambda L_2 = 0$，解方程组即可得恒过定点。
- **设而不求与点差法**：圆锥曲线中点弦斜率与中点坐标的关系（$k_{AB} \cdot k_{OM} = -\frac{b^2}{a^2}$）。

### 1.3 分类讨论与退化临界预警（Warnings 机制）
新高考大题极度注重分类讨论，右屏 `warnings` 必须在参数处于临界退化时实时响应：
- **斜率不存在**：当直线垂直于 $x$ 轴（$B=0$ 或 $x_1=x_2$）时，警示点斜式/斜截式失效，必须单独讨论。
- **截距为零**：截距式要求 $a \neq 0$ 且 $b \neq 0$，过原点直线不可设截距式。
- **两点重合 / 分母为零**：两点式在 $x_1=x_2$ 或 $y_1=y_2$ 时分母为 0 失效。
- **圆退化 / 同心圆**：两圆同心（$d=0$）时不存在公切线与公共弦，半径 $r \le 0$ 时退化。

## 🎛️ 二、左屏控制台交互与参数设计规范

### 2.1 层级扁平化流（严禁 3 层嵌套打架）
左屏必须保持纯净紧凑的两级选择结构：
```
第一级：探究主题 (SelectGrid 2×2 或 2+1)
  └── 第二级：【特定形式 (SelectGrid 2+2+1)】或【典型预设 (SelectGrid 2×2)】
        └── 第三级：专属参数调节 (ParamControl)
```
- ❌ **严禁**在模式选择下再套全局预设、再套子形式的多重冲突嵌套。

### 2.2 “黄金 2×2”典型预设网格
- 第一项必须为【自由探究】（`key: "free"`，全参数开放）。
- 其余 3 项为典型特征几何构型（如“垂直相交”、“水平直线”、“勾股经典”）。
- 微描述文字必须 $\le 6$ 个字，杜绝省略号截断。

### 2.3 声明式 `paramMeta` 100% 注册完备性
- **全量注册**：凡在 `paramConfigs` 中引用的参数 key（例如两点式中的 `x1, y1, x2, y2`），必须 100% 在 `src/data/registries/<topic>.ts` 的 `paramMeta` 中定义，**严禁漏配导致滑块丢失**。
- **数学定义域保护**：
  - 圆半径 $r \in [0.5, 5.0]$，严格限制 $r > 0$；
  - 椭圆长半轴 $a > b > 0$；
  - 步长 `step` 适配精度（一般坐标 $0.1 \sim 0.2$，斜率 $0.1$）。
- **退化临界标记**：在 `marks` 中标明退化临界点（如 $A=0$ 水平线、$B=0$ 铅垂线标为 `variant: "critical"`）。

## ✍️ 三、数学公式与 LaTeX 排版规范

### 3.1 多项式标准符号排版（杜绝 `+ -1.0` 瑕疵）
在拼装数学表达式时，必须严格处理正负号与系数 1：
- ❌ **严禁**：`1.0x + -1.0y + -2.0 = 0` 或 `y - 0.0 = 1.0(x - -2.0)`
- ✅ **正确**：使用专用格式化纯函数（如 `formatGeneralEquationLatex`），输出 `x - y - 2.0 = 0` 与 `y = x + 2.0`。

### 3.2 KaTeX 色彩 Token 动态指令绑定（铁律 4C）
- 严禁硬编码 Hex（如 `\color{#EF4444}`）；
- 必须使用 Token 指令：`\color{${MATH_COLORS.paramPrimary}}{a}x^2 + \color{${MATH_COLORS.paramSecondary}}{b}x`。

### 3.3 公式使用前提与条件显式标注
在右屏 `theorems` 中，每个定理必须配有清晰的适用范围 `condition`（例如：截距式必须标明 $a \neq 0 \text{ 且 } b \neq 0$）。

## 🖼️ 四、中屏数形结合与交互避坑防火墙

### 4.1 【防火墙 1】动点拖拽坐标一致性（杜绝乱飞 BUG）
- `InteractivePoint` 的 `onDrag` 回调传出的参数**已经是解算好的数学坐标** `{ x, y }`。
- ❌ **严禁**在回调中再次调用 `designToMath`：
  ```ts
  // ❌ 严重错误（导致二次缩放乱飞）：
  const handleDrag = (pt) => { const mathPt = designToMath(pt.x, pt.y, scale); ... }
  // ✅ 正确写法：
  const handleDrag = (mathPt: Point2D) => {
    onParamChange("x0", Number(mathPt.x.toFixed(1)));
    onParamChange("y0", Number(mathPt.y.toFixed(1)));
  }
  ```

### 4.2 【防火墙 2】画布拖拽与典型预设解耦
- 当学生在画布上直接拖拽任何动点时，系统**必须自动将预设状态切回【自由探究】（`free`）**，并展开全量参数。

### 4.3 【防火墙 3】标签单源避让（杜绝文字重影）
- ❌ **严禁**在 `<InteractivePoint label="P(x, y)" />` 传 `label` 的同时又在 `avoidLabels` 中渲染同位置文本。
- ✅ **正确做法**：`InteractivePoint` 不传 `label`，所有动点与特征点坐标全量由 `avoidLabels` 统一计算与渲染，保证 0 重影、0 遮挡。

### 4.4 【防火墙 4】几何标尺自适应防畸变
- 直角符号 $\perp$、空间夹角弧线必须根据线段长度动态自适应收敛：
  `const size = Math.min(10 * fontScale(1), vLen * 0.25);`
  防止点靠近直线时直角符号超出垂线段变成巨大异形框。

### 4.5 【防火墙 5】动系的恒过定点可视化呈现
- 演示直线系 $L_1 + \lambda L_2 = 0$ 或圆锥曲线切点弦恒过定点时，中屏必须高亮渲染**交点/定点 $P_0$** 并带有文本标注，让学生看清“绕定点旋转”的几何本质。

### 6.2 标准化页面审计 5 步执行法（SOP）
1. **第 1 步【查大纲与数学完备度】**：对照新高考要求，确认所有经典方程形式、定理与秒杀解法无遗漏。
2. **第 2 步【查左屏层级与滑块】**：确认模式与预设为扁平 2×2 结构，切换子模式确认滑块全部正常显示（`paramMeta` 零遗漏）。
3. **第 3 步【查中屏拖拽与几何标记】**：直接拖拽动点测试是否丝滑跟手、预设是否自动回归 `free`、直角标尺是否精致无畸变。
4. **第 4 步【查右屏看板与符号排版】**：确认中屏悬浮公式符号规范、右屏首项数学量与核心定理随左屏 100% 动态跟随。
5. **第 5 步【全量工程构建】**：执行全量编译，确保 `Exit code 0`，零 TypeScript 类型报错与零警告。
