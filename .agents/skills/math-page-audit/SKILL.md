## 📐 一、高中数学教学需求与新高考考点审计

### 1.1 形式与定理完备度（杜绝漏项）
- **解析几何全家桶**：
  - **直线方程**：必须完整涵盖 5 种形式（一般式、斜截式、点斜式、截距式、两点式），且均可自由调节。
  - **圆与圆系**：圆的标准方程、一般方程、点线圆位置关系、两圆公共弦/根轴、内外公切线。
  - **圆锥曲线**：焦点、准线、通径、离心率、渐近线、焦点三角形、参数方程。
- **函数与导数全家桶**：
  - 切线方程（切点在曲线上 vs 过曲线外一点）、单调区间与极值点、零点存在性、导数同构与放缩。

### 1.2 新高考解题大招与核心思维呈现
右屏 `gaokaoPoints` 必须提炼高考实战秒杀思维，杜绝单纯照抄教材概念：
- **作差法速算**：两圆方程相减即得相交弦/根轴方程 $C_1 - C_2 = 0$。
- **勾股弦长法**：直线与圆弦长优先利用弦心距 $L = 2\sqrt{R^2 - d^2}$，避免联立二次方程求交点。
- **分离参数法求定点**：含参直线 $(A_1+\lambda A_2)x + (B_1+\lambda B_2)y + (C_1+\lambda C_2) = 0$ 整理为 $L_1 + \lambda L_2 = 0$，解方程组即可得恒过定点。
- **设而不求与点差法**：圆锥曲线中点弦斜率与中点坐标的关系（$k_{AB} \cdot k_{OM} = -\frac{b^2}{a^2}$）。

### 1.3 分类讨论与退化临界预警（Warnings 机制）
新高考大题极度注重分类讨论，右屏 `warnings` 必须在参数处于临界退化时实时响应：
- **斜率不存在**：当直线垂直于 $x$ 轴（$B=0$ 或 $x_1=x_2$）时，警示点斜式/斜截式失效，必须单独讨论。
- **截距为零**：截距式要求 $a \neq 0$ 且 $b \neq 0$，过原点直线不可设截距式。
- **两点重合 / 分母为零**：两点式在 $x_1=x_2$ 或 $y_1=y_2$ 时分母为 0 失效。
- **圆退化 / 同心圆**：两圆同心（$d=0$）时不存在公切线与公共弦，半径 $r \le 0$ 时退化。

## 🎛️ 二、左屏控制台交互与参数设计规范

### 2.1 层级扁平化流（严禁 3 层嵌套打架）
左屏必须保持纯净紧凑的两级选择结构：
```
第一级：探究主题 (SelectGrid 2×2 或 2+1)
  └── 第二级：【特定形式 (SelectGrid 2+2+1)】或【典型预设 (SelectGrid 2×2)】
        └── 第三级：专属参数调节 (ParamControl)
```
- ❌ **严禁**在模式选择下再套全局预设、再套子形式的多重冲突嵌套。

### 2.2 内容优先与自适应网格原则（杜绝机械死板套用 2×2）
- **内容完整性第一铁律**：排版必须以“**内容 100% 完整显示、杜绝任何文字/公式省略号截断（`...`）**”为最高前提。
- **动态自适应选列规则**：
  1. **短文本 / 紧凑公式（$\le 5$ 字）**：采用 `columns: 2`（2×2 对称网格或 2+2+1 结构），紧凑美观。
  2. **长描述 / 复杂 LaTeX 分式 / 长名称（$> 6$ 字）**：**必须果断采用单列全宽显示（`columns: 1` 或某项 `fullWidth: true`）**，严禁强行将长文字塞入 2 列导致挤压、换行残缺或出现省略号截断！
- **典型预设结构规范**：
  - 预设首项统一为【自由探究】（`key: "free"`，全参数开放）；
  - 其余项为典型几何构型，若短描述可在 2×2 网格，若含推导解释则使用单列列表。

### 2.3 声明式 `paramMeta` 100% 注册完备性
- **全量注册**：凡在 `paramConfigs` 中引用的参数 key（例如两点式中的 `x1, y1, x2, y2`），必须 100% 在 `src/data/registries/<topic>.ts` 的 `paramMeta` 中定义，**严禁漏配导致滑块丢失**。
- **数学定义域保护**：
  - 圆半径 $r \in [0.5, 5.0]$，严格限制 $r > 0$；
  - 椭圆长半轴 $a > b > 0$；
  - 步长 `step` 适配精度（一般坐标 $0.1 \sim 0.2$，斜率 $0.1$）。
- **退化临界标记**：在 `marks` 中标明退化临界点（如 $A=0$ 水平线、$B=0$ 铅垂线标为 `variant: "critical"`）。

### 2.4 教学需求驱动的参数分层与高中规范命名（主次分明，契合数学习惯）
- **【原则 1：教学需求驱动的主控参数全量呈现】**：
  - 凡是直接服务于当前探究目标的核心数学参数（如直线与圆关系中的斜率 $k$、截距 $m$、半径 $r$；切线模式下的圆外点坐标 $(x_P, y_P)$；二次函数的 $a, b, c$ 等），**必须全量展开并清晰呈现**，保障教学探究的完整性，不搞机械的一刀切裁剪。
- **【原则 2：辅助性质与从属平移参数的层级收拢】**：
  - 对于不改变相对几何本质的刚体平移量（如标准方程下的圆心偏移 $(a, b)$）或从属辅助参数，属于辅助性质，默认收拢或提供折叠开关，亦可在中屏直接交互，避免干扰核心教学主线。
- **【原则 3：100% 契合高中数学课标的学术命名】**：
  - 参数必须采用标准数学名称与符号（如“直线斜率 $k$”、“直线截距 $m$”、“圆半径 $r$”、“圆心横坐标 $a$”、“点 $P$ 横坐标 $x_P$”）；
  - KaTeX 公式必须严谨规范（$x_P, y_P, x_M, y_M, a, b, r, k, m$），**严禁使用 `Px, Py, Mx, My, a坐标` 等非数学专业程序员缩写**。

### 2.5 参数对象化自然聚合与 group 命名规范（同图元归组，主次分层）
- **同图元自然聚合**：凡属于同一几何对象（如定点 $P_0(x_0, y_0)$、弦中点 $M(x_0, y_0)$、向量分量、复数实虚部）的参数，必须配置相同的 `group` 属性（如 `"定点 P₀(x₀, y₀) 坐标"`），杜绝散落平铺；
- **主次分层展示**：第一视线区展示当前探究的核心动量组，几何底模参数（如曲线半轴 $a, b$、焦准距 $p$、圆半径 $r$）聚合成底模组排在后方。

## ✍️ 三、数学公式与 LaTeX 排版规范

### 3.1 多项式标准符号排版（杜绝 `+ -1.0` 瑕疵）
在拼装数学表达式时，必须严格处理正负号与系数 1：
- ❌ **严禁**：`1.0x + -1.0y + -2.0 = 0` 或 `y - 0.0 = 1.0(x - -2.0)` 或 `y = 0.75x 0`
- ✅ **正确**：使用专用格式化纯函数，输出 `x - y - 2.0 = 0` 与 `y = x + 2.0`（0 项与 1 系数严格消元）。

### 3.2 KaTeX 色彩 Token 动态指令绑定（铁律 4C）
- 严禁硬编码 Hex（如 `\color{#EF4444}`）；
- 必须使用 Token 指令：`\color{${MATH_COLORS.paramPrimary}}{a}x^2 + \color{${MATH_COLORS.paramSecondary}}{b}x`。

### 3.3 公式使用前提与条件显式标注
在右屏 `theorems` 中，每个定理必须配有清晰的适用范围 `condition`（例如：截距式必须标明 $a \neq 0 \text{ 且 } b \neq 0$）。

## 🖼️ 四、中屏数形结合与交互避坑防火墙

### 4.1 【防火墙 1】动点拖拽坐标一致性（杜绝乱飞 BUG）
- `InteractivePoint` 的 `onDrag` 回调传出的参数**已经是解算好的数学坐标** `{ x, y }`。
- ❌ **严禁**在回调中再次调用 `designToMath`：
  ```ts
  // ❌ 严重错误（导致二次缩放乱飞）：
  const handleDrag = (pt) => { const mathPt = designToMath(pt.x, pt.y, scale); ... }
  // ✅ 正确写法：
  const handleDrag = (mathPt: Point2D) => {
    onParamChange("x0", Number(mathPt.x.toFixed(1)));
    onParamChange("y0", Number(mathPt.y.toFixed(1)));
  }
  ```

### 4.2 【防火墙 2】画布拖拽与典型预设解耦
- 当学生在画布上直接拖拽任何动点时，系统**必须自动将预设状态切回【自由探究】（`free`）**，并展开全量参数。

### 4.3 【防火墙 3】纯字母点标与单源避让（杜绝文字重影与白框断线）
- **纯字母点标**：中屏几何图形上仅标标准单字母（如 $C, H, A, B, T, M, P$），**严禁直接在画布点旁堆砌 `C(0.0, 0.0)` 等长串坐标数值**（坐标 100% 归位右屏看板）。
- **无遮挡微描边**：文字标签采用 `paintOrder="stroke" stroke="white" strokeWidth={3}` 微描边，**严禁添加 `<rect>` 白底框遮断背后的几何线条**。
- **单源避让**：`InteractivePoint` 不传 `label`，所有点文本统一由 `avoidLabelOverlap` 调度，保证 0 重影。

### 4.4 【防火墙 4】几何标尺防畸变与纯净坐标系
- **标尺防畸变**：直角符号 $\perp$ 边长固定为 9~10px（严禁写 `10 * fontScale(1)`，因 clamp 保护会算出 70px 巨框）：
  `const size = Math.min(10, vLen * 0.35);`
- **纯净坐标系规范**：解析几何中 `CoordinateGrid` 默认使用 `showGrid={false}`（纯白底色 + 清晰 $xOy$ 坐标主轴与整数刻度，杜绝满屏灰色虚线方格网造成视觉干扰）。

### 4.5 【防火墙 5】临界状态全要素穿透审查（杜绝临界动画图元丢失）
在开发与审查几何位置关系时，必须单独对**相切/退化/极值等临界状态**进行图元穿透检查：
- **相切临界状态清单**：
  - [ ] **切点 $T$**：呈现唯一实心点与单字母标注 **$T$**（严禁 $H$ 与 $A$ 两点重叠）；
  - [ ] **切点半径 $CT$**：鲜红实线连接圆心与切点（严禁相切时半径线丢失）；
  - [ ] **垂直性质标尺**：在切点 $T$ 处精准渲染直角折线方框 ∟（展示 $CT \perp l$）；
  - [ ] **代数几何协同**：中屏公式显示 $\Delta = 0, d = r$，右屏弦长归零。
- **动系的恒过定点呈现**：演示直线系 $L_1 + \lambda L_2 = 0$ 或圆锥曲线切点弦恒过定点时，中屏必须高亮渲染**交点/定点 $P_0$** 并带有文本标注，让学生看清“绕定点旋转”的几何本质。

### 6.2 标准化页面审计 5 步执行法（SOP）
1. **第 1 步【查大纲与数学完备度】**：对照新高考要求，确认所有经典方程形式、定理与秒杀解法无遗漏。
2. **第 2 步【查左屏层级与教学参数设计】**：
   - 验证主控核心参数是否全量清晰呈现、从属平移参数是否合理收拢、命名是否 100% 符合高中课标学术规范；
   - 确认模式与预设为扁平结构，切换子模式确认滑块全部正常显示（`paramMeta` 零遗漏）。
3. **第 3 步【查中屏临界与几何标记】**：
   - 逐一点击典型预设（特别是【临界相切】、【直径最大弦】、【垂直最短弦】），核查切点半径、直角标尺、特征点图元是否齐全无遗漏；
   - 拖拽动点测试是否丝滑跟手、预设是否自动回归 `free`、直角标尺是否精致无畸变。
4. **第 4 步【查右屏看板与符号排版】**：确认中屏悬浮公式符号规范、右屏首项数学量与核心定理随左屏 100% 动态跟随。
5. **第 5 步【全量工程构建】**：执行全量编译，确保 `Exit code 0`，零 TypeScript 类型报错与零警告。
