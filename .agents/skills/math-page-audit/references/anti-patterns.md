## 🚫 反模式 1：动点拖拽二次坐标转换（导致动点乱飞脱轨）

### ❌ 错误写法
```tsx
// 错误：InteractivePoint 吐出的已经是经过逆解算的数学坐标 (mathX, mathY)
const handleDrag = (x: number, y: number) => {
  const mathPos = designToMath(x, y, scale); // 💣 二次转换！导致动点瞬移或飞出画布
  setParams({ x0: mathPos.x });
};
```
### ✅ 正确写法
```tsx
const handleDrag = (mathX: number, mathY: number) => {
  setParams({ x0: mathX }); // 直接消费数学坐标
};
```

## 🚫 反模式 6：推演与分析步骤教条化一刀切（全学科通用）

### ❌ 典型违规表现
不顾具体数学情境与退化临界点，机械硬编码固定的操作步数或分析套路，虚构原本不存在的步骤或分支：
1. **立体几何**：无论题设几何构型是什么（即使是两两同面的三角形截面，或对边平行的梯形截面），均机械硬编码为相同的 4 步（硬塞延长求交轨外点与底面交线），虚构原本不存在的体外辅助线；
2. **函数与导数**：当导函数 $f'(x) \ge 0$ 恒成立或参数退化单调无极值时，机械套用“求导 $\to$ 驻点 $\to$ 列表三段讨论 $\to$ 最值”的固定模板，在无根情况下强行划分不存在的讨论区间；
3. **解析几何**：当直线斜率不存在（垂直于 $x$ 轴）或对称于轴线时，机械死套斜截式 $y=kx+m$ 联立方程，导致分母为零或判别式退化；
4. **数列与递推**：当数列直接满足等差/等比定义时，强套错位相减法或裂项相消的多步推演。

### ✅ 正确规范（因题制宜自适应）
```tsx
// 正确范例 1【立体几何】：自适应判定几何构型动态输出步数与选项
// 直接连线法（2步：同面闭合）、平行线法（3步：面面平行性质）、交轨延长线法（4步：求外点交线）
<SelectGrid
  items={constructionData.stepOptions.map(opt => ({
    key: String(opt.step),
    label: opt.label,
    description: opt.description,
  }))}
  value={String(Math.min(step, constructionData.totalSteps))}
  columns={2}
/>

// 正确范例 2【函数与导数】：根据导函数判别式 Delta 或根的存在性自适应分支
const reasoningSteps = hasRoots
  ? [
      { step: 'Step 1', title: '求导定驻点', expression: `f'(x) = 0 \\implies x_1 = ${r1}, x_2 = ${r2}` },
      { step: 'Step 2', title: '单调性列表', expression: '划分单调区间并判定极值符号' },
      { step: 'Step 3', title: '最值与端点比较', expression: '综合比较极值与端点函数值' },
    ]
  : [
      { step: 'Step 1', title: '求导判断符号', expression: `f'(x) > 0 \\text{ 恒成立}` },
      { step: 'Step 2', title: '单调性与最值直接求解', expression: '单调递增，最值在区间端点取得' },
    ];
```

## 🚫 反模式 7：脱离高中课标的计算机/工程化参数建模（全学科通用）

### ❌ 典型违规表现
使用图形学视角、物理引擎参数、矩阵算子或高数冷僻公式代替高考新课标标准题设参数，导致学生无法在真实考题中迁移应用：
1. **立体几何**：在左屏提供计算机图形学球坐标切面参数（切面高度 $z_0$、二面倾角 $\theta$、切向方位角 $\varphi$），学生完全无法理解参数控制什么；
2. **解析几何**：使用计算机齐次坐标变换矩阵或欧拉旋转角，而不是课标标准直线的点斜/斜截式参数 $(k, b)$、动点坐标 $(x_0, y_0)$、圆锥曲线几何量 $(a, b, c, e, p)$；
3. **函数与导数**：脱离高中函数定义域自造无界实数参数，或使用图形学噪声因子，导致函数在高中合法区间外穿透溢出；
4. **概率与统计**：直接暴露晦涩的后台算法浮点参量（如连续分布平滑带宽、未经标准化的矩阵参数），而不是课标标准的样本容量 $n$、事件概率 $P(A)$、灵敏度与特异度。

### ✅ 正确规范（100% 回归新课标教材题设体系）
```tsx
// 1. 立体几何：回归课标已知点/动点比例建模
<ParamControl params={["posP", "posQ", "posR"]} /> // 棱上动点位置比值 t in [0, 1]

// 2. 解析几何：回归直线与圆锥曲线标准几何量
<ParamControl params={["slopeK", "interceptB", "eccentricityE"]} />

// 3. 函数与导数：回归标准函数解析式系数并保护高中定义域
<ParamControl params={["amplitudeA", "omega", "phasePhi"]} />

// 4. 概率统计：回归真实生活与实验样本参数
<ParamControl params={["sampleSizeN", "priorProb", "sensitivity"]} />
```

## 🚫 反模式 8：右屏解答题推导链“空降数值”与题设已知断层脱节（全学科通用）

### ❌ 典型违规表现
推导过程跳过关键数学定理、核心关联方程与代数化简过程，直接把底层代码解算出的浮点数或结论砸给学生：
- “第一步：截面法向量为 $\vec{n} = (0.57, 0.57, 0.57)$” —— 学生疑惑：法向量怎么冒出来的？垂直方程组在哪？
- “第一步：直线与椭圆相交所得弦长为 $L = 3.24$” —— 学生疑惑：没有联立二次方程，没有韦达定理，弦长从何而来？
- “第一步：函数极小值为 $-1.38$” —— 学生疑惑：驻点怎么求的？单调表在哪里？
- “第一步：后验患病概率为 $P(A|B) = 0.165$” —— 学生疑惑：全概率公式分母展开式呢？

### ✅ 正确规范（严格遵循高考解答题采分点三要素闭环）
**三要素闭环**：`题设已知条件/设元` $\to$ `核心关联方程/定理展开` $\to$ `代数求解与当前参数数值代入`。

| 学科专题 | 规范推导演绎链 (Step 1 $\to$ Step 2 $\to$ Step 3) |
| :--- | :--- |
| **立体几何** | 标定已知点坐标与向量 $\to$ 列垂直方程组 $\begin{cases}\vec{n}\cdot\vec{PQ}=0\\\vec{n}\cdot\vec{PR}=0\end{cases}$ 求解法向量与 $\cos\theta$ $\to$ 射影面积公式 $S_{\text{截}}=\frac{S_{\text{投}}}{\cos\theta}$ |
| **解析几何** | 直线与曲线方程联立整理为 $Ax^2+Bx+C=0$ $\to$ 计算 $\Delta>0$ 并写出韦达定理 $x_1+x_2, x_1x_2$ $\to$ 弦长公式 $L=\sqrt{1+k^2}\sqrt{(x_1+x_2)^2-4x_1x_2}$ |
| **函数导数** | 声明定义域并规范求导 $f'(x)$ $\to$ 令 $f'(x)=0$ 因式分解求驻点，列表讨论单调区间 $\to$ 极值计算与区间端点最值比较 |
| **概率统计** | 设出事件并列出先验/条件概率 $\to$ 全概率公式展开分母 $P(B)=P(A)P(B\|A)+P(\bar{A})P(B\|\bar{A})$ $\to$ 代入贝叶斯公式计算后验概率 |
| **数列递推** | 识别递推特征列出关系式 $\to$ 构造辅助等比/等差模型（如待定系数法、不动点方程） $\to$ 求通项公式 $a_n$ 并代入首项检验闭环 |
