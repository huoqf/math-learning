# 高中数学页面质量与高考合规性审计核查表 (Audit Checklist)

> 本清单用于页面新建、重构交付前的逐项自检或复查。

---

## 一、课型定位与架构分流自检

- [ ] **课型明确**：页面已明确标注为 **A 类基础概念课** 还是 **B 类高考专题/大题课**。
  - **A 类课**：右屏仅装配核心定义、数学性质与特征解，**严禁生塞大题三步破题推演**。
  - **B 类课**：右屏必须装配 `reasoningSteps`（带采分点）、`gaokaoPoints`（高考秒杀考点）与 `invariants`（定值不变量）。

---

## 二、左屏控制台交互合规性 (Left Panel)

- [ ] **动线规范**：遵循 `模式维度(TabSwitcher) → 典型情景(SelectGrid) → 参数调节(ParamControl) → 教学导引(TipCard)`。
- [ ] **课标参数合规性**：参数必须 100% 对应高中教材标准题设（如函数系数、解几斜率截距与离心率、立几已知点比例 $t$、概率样本量 $n$ 与事件概率），**严禁出现脱离教材的计算机/工程化建模（如球坐标切面、高维噪声参量）**。
- [ ] **推演步骤因题制宜**：若含推演/作图控制器，步数与分支必须因题自适应（如立几截面 2/3/4 步、导数符号无根单调区间自适应、解几垂直轴特化），**严禁教条化一刀切硬编码固定步数**。
- [ ] **参数分组**：参数数量 $\ge 4$ 时，必须通过 `group` 显式分层（核心探究变量置顶，静态底模尺寸沉底）。
- [ ] **参数映射**：`Animation.tsx` 的 `mapKeysToConfigs` 必须解构并透传 `group: meta.group`。
- [ ] **标签三位一体**：滑块标签包含中文含义 + 课标代号 + 动态色彩（`\text{含义 } \color{Token}{代号}`），严禁孤立英文字母。
- [ ] **Marks 防撞车**：除数学临界分水岭（如 $a=0$、不可导点、$\Delta=0$）配置单个 `critical` 标注外，无密集的平铺刻度。
- [ ] **TipCard 双要素与全学科多级联动闭环**：置于左屏最底部，严格包含【初始条件】（讲清题设全貌，带入当前具体选项解析式/几何方程）+【核心设问】（梯级设问，与右屏推导链构成“左问右解”闭环，严禁提前剧透极值或解题过程）；凡左屏存在 `SelectGrid` 或二级情景/模型选项，`TipCard` 必须 100% 动态联动特化，严禁选项切换而提示不变。

---

## 三、中屏数形结合与作图规范 (Center Canvas)

- [ ] **坐标纯净度**：`CoordinateGrid` 建议 `showGrid={false}`，无满屏方格网干扰。
- [ ] **点标学术化**：画布内点标统一使用 `<SceneLabelGroup>` 渲染纯代数符号，**严禁手写 `<text>` 渲染随拖拽跳动的浮点坐标**。
- [ ] **作图逐帧同步**：在几何作图推演场景中，未完成闭合的前置步骤严禁提前渲染实心面片与射影阴影；闭合生成实体后才同步渲染面片与面积标签。
- [ ] **图例一致性**：中屏右下角 `<SceneLegend>` 完整罗列解析式与几何释义，图例配置的 `colorKey` 与实际绘制图元颜色 1-to-1 绝对一致。
- [ ] **动点解算规范**：`InteractivePoint` 拖拽回调已是数学坐标，**严禁二次调用 `designToMath`**。
- [ ] **预设与交互联动**：画布拖拽动点时，系统自动切回【自由探索】（`free`）并展开全量参数。
- [ ] **图层联动闭环**：关闭父级图层（如截面、投影、球体）时，派生的从属图元（垂足、标尺、交点）100% 同步隐藏。

---

## 四、右屏看板与学术代数规范 (Right Panel)

> 💡 **单一事实源 (SSOT)**：右屏字段分层、推导链三要素（审题定法 $\to$ 建模联立 $\to$ 求解反思）与各学科防断层铁律，以 [right-panel-spec.md](../../new-math-animation/references/right-panel-spec.md#7-高中数学学科认知与破题推演准则-理顺思路--助力掌握) 为唯一标准。

- [ ] **左问右解闭环**：左屏 TipCard 提出的设问 $(1),(2),(3)$，在右屏有明确对应的推演载体与推导结论。
- [ ] **推导链严格对齐已知（拒绝空降数值）**：推导过程严格遵守 [right-panel-spec.md](../../new-math-animation/references/right-panel-spec.md#7-高中数学学科认知与破题推演准则-理顺思路--助力掌握) 第 7 节标准架构，遵循 `题设已知条件/设元` $\to$ `核心关联方程/定理展开` $\to$ `代数求解与当前参数数值代入` 的三要素闭环，**严禁直接凭空扔出浮点数或跳步给答案**。
- [ ] **色彩三位一体**：主控参数（红）、从属参数（橙）、高维参数（绿）在左屏滑块、中屏图形与右屏公式中 100% 同色。
- [ ] **学术代数消元**：无代码变量污染（如暴露 `xa`, `det`）；系数为 1 省略，正负号规范（无 `+ -` 出现）。
- [ ] **定理适用前提**：所有定理显式给出 `condition`（如分母非零、判别式大于零、底数非 1 且大于零）。
