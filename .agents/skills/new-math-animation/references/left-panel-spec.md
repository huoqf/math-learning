# 左屏面板组件系统与紧凑排版指南 (LeftPanel Spec)

> 规范高中数学可视化动画中左屏（LeftPanel）的动线层级、组件用法与空间紧凑化原则。
> 保证在物理宽度 240px ~ 280px 的有限空间内，实现高质感、逻辑顺畅、标题无截断、零滚动体验。

---

## 🎯 一、核心认知：左屏空间的物理约束

- **物理宽度**：标准桌面（$\ge 1440\text{px}$）为 `280px`；紧凑桌面（$1280\sim 1439\text{px}$）为 `240px`。
- **内边距标准**：`LeftPanel` 为 `p-3 gap-2.5`，`LeftPanelSection` 默认 `p-3`（紧凑模式 `p-2`）。
- **可用宽度最大化**：杜绝卡片套卡片、双重白底与嵌套 padding，把宝贵宽度留给按钮标题与滑块轨道。

---

## 📐 二、学科五级自适应动线（自上而下顺畅排布）

所有高中数学页面的左屏布局，统一遵守以下 5 级呈现动线（按需选用，层级不颠倒）：

```text
┌────────────────────────────────────────────────────────┐
│ 1. 探索维度 / 大类模式 (TabSwitcher, Pattern A)          │
│    例：二次函数/方程/不等式；代数/几何；条件/全概/贝叶斯      │
├────────────────────────────────────────────────────────┤
│ 2. 典型情境 / 课标母题 (SelectGrid, Pattern B/C)         │
│    首项固定为【自由探索】(free)，后接高考标准题设预设        │
├────────────────────────────────────────────────────────┤
│ 3. 核心参数调节 (ParamControl, embedded 默认模式)        │
│    随情景降维展开，扁平分组，滑轨舒展，带三位一体色彩标签   │
├────────────────────────────────────────────────────────┤
│ 4. 辅助开关 / 视角控制 (Toggle / 视角切换)               │
│    法向量、辅助线、二面角弧、直观图/三视图切换             │
├────────────────────────────────────────────────────────┤
│ 5. 教学导引与题设背景 (TipCard, 置于底部)                 │
│    标准双要素：【初始条件】+【核心设问】，拒绝提前剧透推导  │
└────────────────────────────────────────────────────────┘
```

## 🧩 三、核心组件标准用法与规范

### 1. `LeftPanelSection`（区块卡片外壳）
- **标题精炼**：仅配置纯粹加粗的 `title`（如 `研究模式`、`参数调节`），**严禁配置口水话 `subtitle`**（如“选择三位一体探讨对象”、“拖动滑块改变参数”）。
- **紧凑模式**：对于仅含开关或教学导引的区域，配置 `compact={true}`（内边距自动降为 `p-2`）。

### 2. `SelectGrid`（选项按钮网格与流式胶囊）
- **容量法则（彻底根治挤爆与单列堆叠）**：
  - **严禁横排 $\ge 4$ 列**：左屏实际可用宽度仅 192~232px，4 列每项不足 50px，字数稍长必截断；
  - **标准 2 列为王（`columns={2}`）**：选项 $\ge 4$ 项时，首选双列网格。长达 5~8 字选项（如“矩形对角线翻折”）自动触发 3 级字符自适应（$\le 4$ 字 12px，5~7 字 11px，$\ge 8$ 字 10px），自然两行居中排开；
  - **奇数项（3 项、5 项）平衡**：首项【自由探索】配置 `fullWidth` 作为单行轻量通栏微条（高 30px），下方其余母题形成标准双列对称；
  - **流式胶囊排版（`layout="flow"`）**：适用于不等长短标签或离散快选（如根的存在性、极值分类），宽度随文字弹性收缩，自然流式折行，无死板留白。
- **轻量边框**：组件内置细腻的 1px 细边框与微光晕，杜绝笨重的 `border-2`。

### 3. `TabSwitcher`（顶层维度切换）
- **横向优先与熔断保护**：
  - 当选项为 2~3 个短词（如“3D直观图 / 2D三视图”）时，使用 `layout="horizontal"` 单行并列；
  - **自动熔断保护**：若选项 $\ge 4$ 项且设置了 `horizontal`，组件自动分流为 2x2 紧凑网格，彻底防止 4 项横排挤爆。
- **自适应文本**：横向模式自适应折行，移除强制 `truncate`，不再产生生硬省略号；
- **尺寸控制**：支持 `size="compact"`（更小内边距与高度）。

### 4. `ParamControl`（参数调节器）
- **彻底消除双重边框**：
  - 默认采用 `variant="embedded"`（透明嵌入模式），**内部不渲染多余的白底卡片边框，不渲染重复的 `参数设置` 标题**；
  - 恢复默认按钮 `onReset`：在 embedded 模式下自动在右上角提供轻巧重置动作，或由 Section 的 `action` 承载。
- **分组（`group`）扁平化**：
  - 严禁在分组时嵌套子卡片（杜绝 `bg-neutral-50 rounded-xl p-3.5`）；
  - 分组采用扁平细分线与极简主色圆条，保留 100% 轨道宽度。
- **滑轨与端点紧凑**：
  - 两端 min/max 标注仅占 `w-6 text-[10px]`，中间滑轨可用长度扩充 20% 以上；
  - 参数项垂直间距精简为 `space-y-1.5 pb-2`，高度压缩 35%~40%。

### 5. `TipCard`（教学导引题设化）
- **结构化 Props 推荐**：
  ```tsx
  <TipCard
    variant={tipConfig.variant}
    badge="高考母题 · 直角梯形翻折"
    condition="在直角梯形 ABCD 中，AB ⊥ AD，沿折痕 AC 翻折..."
    question="探究翻折过程中二面角 α 变化时空间两动点间距的最大值。"
  />
  ```
- **双要素职责分离**：
  - ①【**初始条件**】：用题设基准数据交代背景；
  - ②【**核心设问**】：交代探究目标与问题，**严禁在 TipCard 提前剧透推导过程或最终数值答案**（推导全部归位右屏 `MathPanel`）。

### 6. `Toggle`（辅助开关）
- **尺寸选项**：支持 `size="compact"`（高度缩小为 16px）；
- **并排建议**：当有两个辅助开关时，使用 `<div className="grid grid-cols-2 gap-2">` 单行并排，节省 50% 高度。

## 🚫 四、左屏典型反模式与自查表

| ❌ 严禁反模式 | ✅ 正确做法 |
| :--- | :--- |
| `LeftPanelSection` 内部直接嵌套自带外框的 `ParamControl` 导致双白框双标题 | `ParamControl` 默认 embedded，Section 统一标题 |
| 分组（`group`）时多重嵌套内边距导致滑轨只剩 50px | 扁平分组指示线，全宽滑道 |
| 左屏堆砌 5~6 个独立 Section，每个 Section 仅放 1 个开关 | 开关归并到图层控制 Section，使用双列网格 |
| 在 `subtitle` 写“调节参数观察变化”等口水废话 | 省略 `subtitle`，仅保留精炼加粗 `title` |
| 选项包含 6 个字就降为单列导致左屏无限纵向拉长 | `SelectGrid columns={2}` 紧凑字阶自适应 |
| `TabSwitcher` 横向文字被 `truncate` 截断出省略号 | 移除强制 truncate，采用自适应紧凑排版 |
| `TipCard` 手写大段重复的 JSX 格式各异 | 使用 `TipCard` 结构化 props（`badge`, `condition`, `question`） |
