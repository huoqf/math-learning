## 1. 高中立体几何与空间向量全章节模型图谱

### 专题一：空间点线面位置关系（判定与性质定理）
| 高考核心定理/模型 | 范式归属 | 必标中屏几何图元与辅助线 | 高中数学标准标注约定 |
| :--- | :--- | :--- | :--- |
| **线面平行判定** ($a \not\subset \alpha, b \subset \alpha, a \parallel b \implies a \parallel \alpha$) | 综合几何 | 面内平行基准线 $b$、面外直线 $a$、平行特征指示线 | 标出直线 $a, b$ 与平面 $\alpha$；两线平行不可有坐标轴 |
| **线面平行性质** ($a \parallel \alpha, a \subset \beta, \alpha \cap \beta = b \implies a \parallel b$) | 综合几何 | 相交平面 $\beta$、交线 $b$、虚实交线 | 凸显辅助截面 $\beta$ 与交线 $b$ 的生成过程 |
| **线面垂直判定** ($l \perp m, l \perp n, m \cap n = P \subset \alpha \implies l \perp \alpha$) | 综合几何 | 面内**两条相交直线** $m, n$、垂足 $P$、**错开双直角方框** (`AngleArc3D isRight={true}`) | 必须清晰呈现两个错开的直角符号，强化“相交两直线”前提 |
| **线面垂直性质** ($a \perp \alpha, b \perp \alpha \implies a \parallel b$) | 综合几何 | 双垂足 $A, B$、平面 $\alpha$、垂直符号 | 两垂线在同一平面 $\alpha$ 上的垂足双直角符号 |
| **面面平行判定与性质** | 综合几何 | 平行面内两组相交直线、公垂线段/截面 | 突出面内相交直线对的平行关系 |
| **面面垂直判定与性质** | 综合几何 | 垂面内的垂线、交线、交线垂足直角符号 | 必须在交线上标出垂线与交线的垂直符号，突出“面面垂直转化线面垂直” |

### 专题二：空间三大角（线线角、线面角、二面角）
| 空间角模型 | 求解方法 | 必标中屏几何图元与辅助线 | 高考标准标注约定 |
| :--- | :--- | :--- | :--- |
| **异面直线所成角** | 平移法 / 向量法 | 平移线段（虚线带同向标记）、相交顶点、锐角弧 $\theta \in (0, \frac{\pi}{2}]$ | 必须呈现平移至同一顶点的过程，角弧必须取锐角或直角 |
| **直线与平面所成角** | 射影法 / 向量法 | 斜线 $PA$、垂线段 $PO \perp \alpha$（垂足 $O$）、射影线 $OA$（虚线）、线面角弧 $\angle PAO$ | 必须构成以斜线为斜边的**直角三角形 $\triangle POA$**，垂足 $O$ 标直角，角弧标 $\theta \in [0, \frac{\pi}{2}]$ |
| **二面角（定义法/垂面法）** | 几何法 | 棱 $l$、棱上垂足 $O$、两半平面内的垂线 $OA \perp l, OB \perp l$、平面角弧 $\angle AOB$ | 垂足 $O$ 处标出两个垂直于棱的直角符号，凸显平面角 $\theta \in [0, \pi]$ |
| **二面角（法向量法）** | 解析建系 | 两平面法向量 $\vec{n}_1, \vec{n}_2$、法向量起点（附着在平面中心）、法向量夹角弧 | 必须标明 $\cos\theta = \frac{|\vec{n}_1 \cdot \vec{n}_2|}{|\vec{n}_1||\vec{n}_2|}$ 或根据直观图开口判断钝角/锐角 |

### 专题三：空间距离与体积极值
| 距离/极值模型 | 求解方法 | 必标中屏几何图元与辅助线 | 高考标准标注约定 |
| :--- | :--- | :--- | :--- |
| **点到平面距离** | 垂线段法 / 向量射影法 / 等体积法 | 点 $P$、平面 $\alpha$、射影垂足 $H$、垂线段 $PH$（虚线高线）、垂足双直角符号 | 标出距离 $d=|PH|$；向量法标出面内基准点 $A$ 及向量 $\vec{AP}$ 在法向量 $\vec{n}$ 上的投影 |
| **异面直线距离** | 公垂线法 / 线面平行法 | 两异面直线、公垂线段两端点及双直角符号 | 突出公垂线段的唯一性与最短性 |
| **动点三棱锥体积极值** | 高线动轨迹法 | 底面三角形、动点 $P$ 轨迹线/轨迹面、动高 $h(t)$ | 标出固定底面积 $S_{\text{底}}$ 与动态变化的高 $h$，体现 $V=\frac{1}{3}S h$ 的线性/极值性质 |

### 专题四：多面体与球体切接四大模型
| 外接球/内切球模型 | 核心特征与几何构造 | 必标中屏几何图元与辅助线 | 高考标准标注约定 |
| :--- | :--- | :--- | :--- |
| **墙角模型（三条棱两两垂直）** | 三直角棱 $a, b, c$ 构成三棱锥顶点 | 补全的长方体虚线框、体对角线、外接球球心 $O$（对角线中点）、半径 $R$ | $2R = \sqrt{a^2+b^2+c^2}$，标出体对角线及球心 $O$ |
| **柱体/直棱柱模型** | 侧棱垂直于底面，底面外接圆半径 $r$ | 上下底面外心 $O_1, O_2$、底面外接圆、球心 $O$（外心连线中点）、高 $h$ | 直角三角形 $R^2 = r^2 + (\frac{h}{2})^2$，在空间标出该直角三角形与各边长度 |
| **对棱相等/补形模型** | 四面体三对对棱分别相等 ($a, b, c$) | 补形的长方体虚线框（长宽高 $x, y, z$）、四面体实线棱 | 标出补形关系 $x^2+y^2=a^2, y^2+z^2=b^2, z^2+x^2=c^2$ 与外接球体对角线 |
| **内切球模型** | 多面体各面均与内切球相切 | 球心 $I$ 到各面的垂线段 $r$、各切点、等体积多面体分割虚线 | $r = \frac{3V_{\text{总}}}{S_{\text{表}}}$，标出球心到各面的公垂半径 $r$ |

## 2. 空间视差消除与透视切圆解析解

在透视投影（Perspective Camera）下，球体和曲面轮廓受视距 $d = \|\mathbf{C}\|$ 影响：
- **切圆圆心偏移量**：$h_{\text{rim}} = \frac{R^2}{d}$（沿相机视线方向向前推进）
- **切圆实际透视半径**：$r_{\text{rim}} = \frac{R \sqrt{d^2 - R^2}}{d}$
- **深度测试规范**：固定点 `Point3D`（$r=0.042$）默认开启深度测试（`depthTest: true`），消除点球穿透半透明曲面造成的内凹错觉。

## 3. 标注体系与三位一体色彩映射铁律

1. **顶点与文字**：
   - 几何顶点（$A, B, C \dots$）：100% 使用 `PointLabel3D` / `CompoundLabel3D`，纯 3D 矢量文字。
   - 空间公式符号（$\vec{a}, \vec{n}, \theta$）：使用 `FormulaLabel3D`（plain 模式）。
2. **色彩绑定**：
   - **核心主控参数一**（如 $a, r_1, \lambda$）：`\color{${MATH_COLORS.paramPrimary}}{...}` (`#EF4444`)
   - **次要关联参数二**（如 $b, r_2, \alpha$）：`\color{${MATH_COLORS.paramSecondary}}{...}` (`#D97706`)
   - **辅助或高度参数三**（如 $c, h, \theta$）：`\color{${MATH_COLORS.paramTertiary}}{...}` (`#059669`)
   - **截面与辅助图形**：`MATH_COLORS.accent` (`#3B82F6`)
