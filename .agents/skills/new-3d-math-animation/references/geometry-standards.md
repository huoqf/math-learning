# 3D 几何建模与高考标注规范指南

> 本指南为立体几何与空间向量场景的深入参考资源。在开发旋转体、多面体截面、线面/面面关系页面时按需查阅。

---

## 1. 旋转体几何模型与高考定义规范

| 几何体 | 生成面与旋转轴 | 标准特征点（单一数据源直连 `profile`） | 高考标准标注约定 |
| :--- | :--- | :--- | :--- |
| **圆柱** | 矩形 $OO_1A_1A$ 绕边 $OO_1$ 旋转 | 下底圆心 $O$、上底圆心 $O_1$、下底母线端点 $A$、上底母线端点 $A_1$ | 半径 $OA=O_1A_1=r_1$ 严格同步联动，母线 $A_1A$ 贴合表面；动态旋转时动点 $A_1, A$ 随母线同轴转动 |
| **圆台** | 直角梯形 $OO_1A_1A$ 绕垂直腰 $OO_1$ 旋转 | 下底圆心 $O$、上底圆心 $O_1$、下底端点 $A(r_1)$、上底端点 $A_1(r_2)$ | 下底半径 $r_1$ 与上底半径 $r_2$ 独立可调；母线 $A_1A$ 严格直连两端点 |
| **圆锥** | 直角三角形 $SOA$ 绕直角边 $SO$ 旋转 | 锥体顶点 $S$、底面圆心 $O$、底面母线端点 $A$ | **严格排斥多余的 $A_1, O_1$ 标注**；母线为线段 $SA$ |
| **球体** | 半圆绕直径所在直线旋转 | 球心 $O$、赤道半径端点 $A(R)$ | 外轮廓线采用**透视切圆解析解**，赤道大圆前实后虚拆分 |

## 2. 空间视差消除与透视切圆解析解

在透视投影（Perspective Camera）下，相机拉近或放大时，球面切线构成的可见地平切圆会向相机方向前移：
- **切圆圆心偏移量**：$h_{\text{rim}} = \frac{R^2}{d}$（沿相机视线方向向前推进，其中 $d = \|\mathbf{C}\|$）
- **切圆实际透视半径**：$r_{\text{rim}} = \frac{R \sqrt{d^2 - R^2}}{d}$
- **深度测试规范**：固定点 `Point3D`（$r=0.042$）默认开启深度测试（`depthTest: true`），消除点球穿透半透明曲面造成的内凹错觉。

## 3. 高考定理辅助线与垂直标准标注

1. **线面垂直（$l \perp \alpha$）**：
   - 必须在垂足处标出与面内两条相交直线的**错开双直角方框**（使用 `AngleArc3D isRight={true}`）。
2. **面面垂直（$\alpha \perp \beta$）**：
   - 标出二面角交线处的垂线直角或二面角平面角直角弧 $\theta = 90^\circ$。
3. **多面体高线（如四棱锥 $PO \perp \text{底面}$）**：
   - 垂足 $O$ 处标出 $PO \perp AB$ 与 $PO \perp AD$ 两个直角符号。
4. **截面与射影面积**：
   - 标出截面面积 $S_{\text{截}}$ 与底面射影面积 $S_{\text{射}}$，体现高考射影面积法 $\cos\theta = \frac{S_{\text{射}}}{S_{\text{截}}}$。

## 4. 三位一体色彩与 KaTeX 动态插值

严禁在 3D 材质和 KaTeX 字符串中硬编码字面量 Hex 颜色，必须 100% 采用动态 Token：
- **核心主控参数一**：`\color{${MATH_COLORS.paramPrimary}}{r_1}` (`#EF4444`)
- **次要关联参数二**：`\color{${MATH_COLORS.paramSecondary}}{r_2}` (`#D97706`)
- **辅助/高度参数三**：`\color{${MATH_COLORS.paramTertiary}}{h}` (`#059669`)
- **截面与降维图形**：`MATH_COLORS.accent`
